## A.1 標識符（Identifiers）

### 命名規則
- 第一個字元：**字母** 或 `_`
- 後續字元：字母、數字、`_`
- 字母 = Unicode letter，所以中文也合法（但不建議）：
  ```go
  var 名字 string  // 合法但別寫
  ```

### 大小寫決定可見性（Visibility）

| 開頭 | 範圍 |
|---|---|
| 大寫 | exported（其他 package 可見） |
| 小寫 | unexported（package 內部） |

```go
package mypkg

type User struct {     // 對外可見
    name    string     // 對外不可見（外部無法存取）
    Email   string     // 對外可見
}
```

### 25 個保留關鍵字（不能當變數名）

```
break        default      func         interface    select
case         defer        go           map          struct
chan         else         goto         package      switch
const        fallthrough  if           range        type
continue     for          import       return       var
```

### 預宣告標識符（Predeclared Identifiers）

不是關鍵字，但編譯器在「universe block」預先定義，**可以被 shadow 但別這樣做**：

| 類別 | 名稱 |
|---|---|
| 型別 | `bool` `byte` `complex64` `complex128` `error` `float32` `float64` `int` `int8`...`int64` `rune` `string` `uint` `uint8`...`uint64` `uintptr` `any` `comparable` |
| 常數 | `true` `false` `iota` |
| 零值 | `nil` |
| 函式 | `append` `cap` `clear` `close` `complex` `copy` `delete` `imag` `len` `make` `max` `min` `new` `panic` `print` `println` `real` `recover` |

> 看到有人寫 `var len = 10` 都會皺眉。

## A.2 運算子（Operators）

### 完整列表（按優先序由高到低）

| 等級 | 運算子 | 說明 |
|---|---|---|
| 5 | `* / % << >> & &^` | 乘除、位元 AND |
| 4 | `+ - \| ^` | 加減、位元 OR / XOR |
| 3 | `== != < <= > >=` | 比較 |
| 2 | `&&` | 邏輯 AND |
| 1 | `\|\|` | 邏輯 OR |

### `&^`：位元 AND NOT（清除位元）

```go
x := 0b1100
y := 0b0100
x &^ y  // = 0b1000（把 y 為 1 的位元在 x 裡清掉）
```

### Go **沒有**的運算子
- 三元運算子 `? :`：永遠用 `if`
- 前置 `++` `--`：只有後置；且**是 statement，不是 expression**：
  ```go
  i++           // OK
  j := i++      // ❌ 編譯錯誤
  ```
- 運算子重載（operator overloading）

### 比較規則
- **可比較型別**：bool、數字、string、pointer、channel、interface、struct（所有欄位可比較）、array（元素可比較）
- **不可比較**：slice、map、function（用 `reflect.DeepEqual` 或 `slices.Equal`）

```go
[]int{1,2} == []int{1,2}  // ❌ 編譯錯誤
slices.Equal([]int{1,2}, []int{1,2})  // ✅
```

## A.3 分號自動插入（Automatic Semicolon Insertion）

Go 用分號分隔 statement，但**程式碼幾乎看不到分號**——因為 lexer 會自動補。

### 規則
若一行的最後一個 token 是這些之一，**該行尾自動插 `;`**：

| 類別 | token |
|---|---|
| 識別符 / 字面值 | identifier、int / float / string literal |
| 關鍵字 | `break` `continue` `fallthrough` `return` |
| 運算子 / 標點 | `++` `--` `)` `]` `}` |

### 後果：`{` 必須在同一行

```go
// ✅ 正確
if x > 0 {
    ...
}

// ❌ 錯誤：lexer 在 `x > 0` 後面插 `;`
if x > 0
{
    ...
}
```

這也是為什麼 Go 風格「永遠 `{` 不換行」——不是品味，是語法強制。

## A.4 字串字面值（String Literals）

### 兩種寫法

```go
// 解譯字串（interpreted）：用雙引號，支援逃脫
s1 := "Hello\nWorld\t!中"

// 原始字串（raw）：用反引號，所有字元原樣保留
s2 := `Hello\n
這裡的 \n 是兩個字元，不是換行
"" 也不用逃脫`
```

### 常用逃脫
| 逃脫 | 含義 |
|---|---|
| `\n` | 換行 |
| `\t` | tab |
| `\\` | 反斜線 |
| `\"` | 雙引號 |
| `\xFF` | 十六進位 byte |
| `中` | Unicode 4 hex |
| `\U0001F600` | Unicode 8 hex |

## A.5 數值字面值（Numeric Literals）

### 各種進位

```go
i := 42         // 十進位
i := 0b101010   // 二進位（Go 1.13+）
i := 0o52       // 八進位
i := 052        // 八進位（傳統寫法）
i := 0x2A       // 十六進位

f := 3.14
f := 3.14e2     // 科學記號 = 314.0
f := 0x1.8p1    // 十六進位浮點 = 3.0
```

### Underscore 分隔（Go 1.13+）
```go
million := 1_000_000
hexFlag := 0xCAFE_F00D
```

僅供可讀性，不影響數值。

## A.6 panic / recover

### `panic`：中斷正常流程

```go
panic("invalid input")          // string
panic(errors.New("err"))        // error
panic(struct{ Code int }{1})    // 任何值
```

當 `panic` 發生：
1. 當前函式停止執行
2. 跑完所有 `defer`
3. 回到呼叫者，重複 1-2
4. 一路炸到 main，程式 crash 並印 stack trace

### `recover`：只在 `defer` 中有效

```go
func safeRun(fn func()) {
    defer func() {
        if r := recover(); r != nil {
            log.Printf("panic: %v", r)
        }
    }()
    fn()
}
```

⚠️ 規則：
- `recover` 必須在**直接被 defer 呼叫的函式**裡，不能呼叫一層內部函式再 recover。
- recover 只攔同一個 goroutine 的 panic。**子 goroutine 的 panic 攔不到**。

### 何時用 panic？

| 情況 | 用 panic 嗎 |
|---|---|
| 可預期的錯誤（檔案不存在、網路斷） | ❌ 用 `error` |
| 程式設計者錯誤（不該發生） | ✅ |
| 啟動時關鍵設定缺失 | ✅（讓 main 直接掛） |
| Library 的 public API | ❌ 一律 error |
| 想偷懶不寫錯誤處理 | ❌❌❌ |

## A.7 unsafe 與 reflect（簡介）

### `unsafe.Pointer`
跨型別轉換、與 C 互通用，**繞過型別系統**：

```go
import "unsafe"

var x int = 10
p := unsafe.Pointer(&x)
fp := (*float64)(p)  // 把 int 的位址當 float64 看
```

⚠️ 99% 的程式不需要 `unsafe`。用之前先問「是不是該用 cgo / encoding/binary」。

### `reflect`：執行期型別檢查

```go
v := reflect.ValueOf(x)
t := reflect.TypeOf(x)

if v.Kind() == reflect.Struct {
    for i := 0; i < v.NumField(); i++ {
        fmt.Println(v.Field(i))
    }
}
```

主要用於：序列化套件（JSON、ORM）、validator、template engine。
應用程式碼**很少需要直接用**。

## A.8 註解約定（Comment Conventions）

### 文件註解
寫在 export 名稱前，第一個字必須是該名稱：

```go
// User 代表一位系統使用者。
// 它由 ID 唯一識別。
type User struct { ... }

// Save 將 user 寫入後端儲存。
// 若 user.ID 為 0，會自動分配。
func (u *User) Save(ctx context.Context) error { ... }
```

### Package 註解

```go
// Package userrepo 提供 User 的持久化介面。
//
// 所有方法都需要 context.Context 作為第一個參數，
// 用於控制逾時與取消。
package userrepo
```

### 特殊 directive
- `//go:build linux`：build tag
- `//go:embed file.txt`：embed
- `//go:generate`：`go generate` 跑的指令
- `//nolint:errcheck`：略過 lint 規則（極少用）

## A.9 Operator Precedence Cheat Sheet

```
最高 → 最低
   *  /  %  <<  >>  &  &^
   +  -  |  ^
   ==  !=  <  <=  >  >=
   &&
   ||
```

> 跟 C 略有不同：Go 把所有同 level 的位元運算放一起。**不確定優先序時直接加括號**。

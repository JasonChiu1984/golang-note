## 5.1 `encoding/json`：JSON 序列化

### 基本用法

```go
import "encoding/json"

type User struct {
    ID    int    `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email,omitempty"`
    Pwd   string `json:"-"`  // 永遠不序列化
}

// Marshal：struct → JSON bytes
u := User{ID: 1, Name: "Amy"}
data, err := json.Marshal(u)
// {"id":1,"name":"Amy"}

// Unmarshal：JSON bytes → struct
var u2 User
err := json.Unmarshal(data, &u2)  // 注意傳指標
```

### Struct Tag 細節

| Tag | 行為 |
|---|---|
| `json:"name"` | 改欄位名 |
| `json:"name,omitempty"` | 零值時不輸出 |
| `json:"-"` | 永遠忽略 |
| `json:"name,string"` | 數值序列化為字串 |

### Stream API（大檔案）

整個 Marshal / Unmarshal 會把整份資料載入記憶體。處理大檔案用 `Decoder` / `Encoder`：

```go
dec := json.NewDecoder(req.Body)
dec.DisallowUnknownFields()  // 多餘欄位報錯

var u User
if err := dec.Decode(&u); err != nil { ... }
```

### 常見坑

| 坑 | 解 |
|---|---|
| 大寫欄位才會被 export | JSON 欄位對應的 Go 欄位**必須首字母大寫** |
| `time.Time` 預設是 RFC3339 | 自訂 `MarshalJSON` 或包裝型別 |
| `nil` slice → `null`，`[]int{}` → `[]` | 想要 `[]`，初始化空 slice |
| 浮點精度損失 | 用 `json.Number` 或 string |
| Number 比 int64 大 | 用 `json.Number` 取得字串 |

## 5.2 `net/http`：HTTP 客戶端與伺服器

### Server（最簡）

```go
http.HandleFunc("/hello", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Hello")
})
log.Fatal(http.ListenAndServe(":8080", nil))
```

### Server（生產級）

⭐ 預設的 `http.ListenAndServe` 沒有逾時設定，**生產不要用**。

```go
mux := http.NewServeMux()
mux.HandleFunc("GET /users/{id}", getUser)  // Go 1.22 新語法
mux.HandleFunc("POST /users", createUser)

srv := &http.Server{
    Addr:              ":8080",
    Handler:           mux,
    ReadHeaderTimeout: 5 * time.Second,
    ReadTimeout:       10 * time.Second,
    WriteTimeout:      10 * time.Second,
    IdleTimeout:       60 * time.Second,
    MaxHeaderBytes:    1 << 20,  // 1 MB
}

go srv.ListenAndServe()

// 優雅關閉
sig := make(chan os.Signal, 1)
signal.Notify(sig, os.Interrupt, syscall.SIGTERM)
<-sig

ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()
srv.Shutdown(ctx)
```

### Client：別用 `http.DefaultClient`

```go
// ❌ DefaultClient 沒有逾時，會吊死
resp, _ := http.Get(url)

// ✅ 自己建立帶逾時的 client
client := &http.Client{
    Timeout: 3 * time.Second,
    Transport: &http.Transport{
        MaxIdleConns:        100,
        MaxIdleConnsPerHost: 10,
        IdleConnTimeout:     90 * time.Second,
    },
}

req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
resp, err := client.Do(req)
if err != nil { return err }
defer resp.Body.Close()  // ⭐ 永遠記得 close

body, err := io.ReadAll(resp.Body)
```

### Middleware Pattern

```go
func loggingMW(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()
        next.ServeHTTP(w, r)
        log.Printf("%s %s %v", r.Method, r.URL.Path, time.Since(start))
    })
}

handler := loggingMW(authMW(mux))
```

### Go 1.22 新 ServeMux 語法

```go
mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id")
    fmt.Fprintln(w, "user:", id)
})
```

支援：方法限制（`GET`、`POST`）、路徑變數（`{id}`）、wildcard（`{path...}`）。
但複雜路由（middleware chain、group）仍建議用 `chi` 或 `gin`。

## 5.3 `testing`：單元測試

### 基本測試

檔名 `xxx_test.go`，函式 `func TestXxx(t *testing.T)`：

```go
// math.go
func Add(a, b int) int { return a + b }

// math_test.go
func TestAdd(t *testing.T) {
    got := Add(2, 3)
    if got != 5 {
        t.Errorf("Add(2, 3) = %d; want 5", got)
    }
}
```

跑：`go test ./...`

### Table-Driven Test（標準寫法）

```go
func TestAdd(t *testing.T) {
    tests := []struct {
        name    string
        a, b    int
        want    int
    }{
        {"positive",  2, 3, 5},
        {"negative", -1, 1, 0},
        {"zero",      0, 0, 0},
    }
    for _, tc := range tests {
        t.Run(tc.name, func(t *testing.T) {
            if got := Add(tc.a, tc.b); got != tc.want {
                t.Errorf("Add(%d, %d) = %d; want %d", tc.a, tc.b, got, tc.want)
            }
        })
    }
}
```

`t.Run` 讓每個 case 變成 subtest，失敗也能繼續跑剩下的。

### `t.Errorf` vs `t.Fatalf`

- `t.Errorf`：記錄失敗、**繼續跑**
- `t.Fatalf`：記錄失敗、**立即停止**這個 test
- `t.Helper()`：讓錯誤訊息指向呼叫端而不是 helper

### 範例：Helper

```go
func mustParse(t *testing.T, s string) time.Time {
    t.Helper()
    tm, err := time.Parse(time.RFC3339, s)
    if err != nil { t.Fatalf("parse %q: %v", s, err) }
    return tm
}
```

### Benchmark

函式名 `BenchmarkXxx(b *testing.B)`：

```go
func BenchmarkAdd(b *testing.B) {
    for i := 0; i < b.N; i++ {
        Add(2, 3)
    }
}
```

跑：`go test -bench=. -benchmem`

### Fuzz Test（Go 1.18+）

```go
func FuzzReverse(f *testing.F) {
    f.Add("hello")
    f.Fuzz(func(t *testing.T, s string) {
        rev := Reverse(Reverse(s))
        if rev != s {
            t.Errorf("double reverse mismatch: %q", s)
        }
    })
}
```

跑：`go test -fuzz=Fuzz`

### 並行測試

```go
func TestX(t *testing.T) {
    t.Parallel()  // 與其他 t.Parallel 的 test 並行
    // ...
}
```

### Coverage

```bash
go test -cover ./...
go test -coverprofile=cov.out ./...
go tool cover -html=cov.out
```

## 5.4 檔案 I/O：`os`、`io`、`bufio`

### 一次讀整檔（小檔）

```go
data, err := os.ReadFile("config.yaml")
err = os.WriteFile("out.txt", data, 0644)
```

### Stream 讀（大檔）

```go
f, err := os.Open("big.log")
if err != nil { return err }
defer f.Close()

scanner := bufio.NewScanner(f)
for scanner.Scan() {
    line := scanner.Text()
    process(line)
}
if err := scanner.Err(); err != nil { return err }
```

> ⚠️ Scanner 預設行長上限 64KB，超過會錯。用 `scanner.Buffer(make([]byte, 1<<20), 1<<20)` 提高。

### 寫入

```go
f, err := os.Create("out.txt")
if err != nil { return err }
defer f.Close()

w := bufio.NewWriter(f)
defer w.Flush()  // ⭐ 別忘了 Flush

fmt.Fprintln(w, "hello")
```

### 路徑處理

```go
import "path/filepath"

abs, _ := filepath.Abs("./foo")
dir := filepath.Dir(path)
base := filepath.Base(path)
ext := filepath.Ext(path)         // ".go"
joined := filepath.Join("a", "b") // 跨平台
```

## 5.5 `time`：時間處理

```go
now := time.Now()
later := now.Add(2 * time.Hour)
diff := later.Sub(now)              // Duration

// 格式化（Go 用「特殊參考時間」而非 strftime）
// 參考時間：Mon Jan 2 15:04:05 MST 2006 = 01/02 03:04:05PM '06 -0700
fmt.Println(now.Format("2006-01-02 15:04:05"))
fmt.Println(now.Format(time.RFC3339))

// 解析
t, err := time.Parse("2006-01-02", "2026-05-10")
t, err := time.Parse(time.RFC3339, "2026-05-10T12:00:00Z")

// Duration
d := 3 * time.Second
d := 500 * time.Millisecond
```

⚠️ 那個「2006-01-02 15:04:05」不是隨便挑的：
- 月 `01`、日 `02`、時 `03`（PM）、分 `04`、秒 `05`、年 `06`、時區 `-0700`
- 順序好記：1, 2, 3, 4, 5, 6, 7

## 5.6 `context`：取消、逾時、傳值

`context.Context` 是 Go 後端的「跨層生命週期管理」核心。

```go
import "context"

// 1. 帶逾時
ctx, cancel := context.WithTimeout(parent, 5*time.Second)
defer cancel()

// 2. 帶 deadline
ctx, cancel := context.WithDeadline(parent, time.Now().Add(5*time.Second))

// 3. 可手動取消
ctx, cancel := context.WithCancel(parent)
go func() { time.Sleep(2*time.Second); cancel() }()

// 4. 帶值（小心使用）
ctx := context.WithValue(parent, userIDKey{}, 42)
```

### 慣用模式

```go
// 函式第一個參數一律 ctx
func GetUser(ctx context.Context, id int) (*User, error) {
    // 把 ctx 傳給下游
    row := db.QueryRowContext(ctx, "SELECT ...", id)
    // ...
}
```

⭐ 規則：
- **每個 I/O 函式都接受 `ctx`**。
- **第一個參數一律 ctx**。
- **不要把 ctx 存進 struct**（除了 server 的長生命週期）。
- **`context.WithValue` 只放「請求生命週期」資訊**（trace ID、user ID），不放 config。

### Cancellation 傳播

```go
func slowOp(ctx context.Context) error {
    select {
    case <-time.After(10 * time.Second):
        return nil
    case <-ctx.Done():
        return ctx.Err()  // context.Canceled / DeadlineExceeded
    }
}
```

## 5.8 Idiom 與 Anti-pattern

### ✅ Idiom
- HTTP client 自己建立並設逾時
- 大檔案用 stream（`bufio` / `Encoder` / `Decoder`）
- table-driven test + `t.Run`
- ctx 一定當第一個參數
- 結構化日誌用 `log/slog`

### ❌ Anti-pattern
- 用 `http.DefaultClient` / `http.Get` 在生產環境
- 整檔讀進記憶體再處理大檔
- `panic(err)` 在 test 裡（用 `t.Fatalf`）
- `context.TODO()` 沒換成真正的 ctx
- 用全域 `log.Println` 取代結構化 log

## 重點回顧

- JSON：`Marshal/Unmarshal`、struct tag、stream API。
- HTTP：自己建 server / client、設逾時、middleware、Go 1.22 新路由。
- Test：table-driven、`t.Run`、benchmark、fuzz、coverage。
- 檔案：小檔 `os.ReadFile`、大檔 `bufio.Scanner`。
- `time`：「2006-01-02 15:04:05」格式記憶口訣。
- `context`：取消、逾時、值；第一個參數規則。

# 附錄 C 中英術語對照表（Glossary）

> 中英對照 + 一句話定義。用 `Cmd-F` 查最快。

---

## C.1 語言核心（Language Core）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 套件 | package | 同目錄下宣告同 `package X` 的程式檔組成的單位 |
| 模組 | module | 由 `go.mod` 標示的依賴版本邊界，包含一個以上 package |
| 識別符 | identifier | 變數、型別、函式等的名稱 |
| 關鍵字 | keyword | 25 個保留字，不可作識別符 |
| 預宣告標識符 | predeclared identifier | `int`、`nil`、`make` 等內建名稱 |
| 短宣告 | short variable declaration | `x := 1`，僅函式內可用 |
| 型別推論 | type inference | 編譯器從右值推出左邊變數型別 |
| 零值 | zero value | 變數宣告未賦值時的預設值 |
| 型別斷言 | type assertion | `x.(T)`，把 interface 還原為具體型別 |
| 型別轉換 | type conversion | `int(x)`，顯式轉成另一型別 |
| 型別定義 | type definition | `type A B`，建立新型別 |
| 型別別名 | type alias | `type A = B`，A 與 B 等同 |
| 型別參數 | type parameter | 泛型函式 `[T any]` 中的 T |
| 約束 | constraint | 型別參數可接受的型別集合（`any`、`comparable`） |
| 嵌入 | embedding | struct 或 interface 內含另一型別，提升其欄位/方法 |
| 提升的方法 | promoted method | 由 embedding 自動繼承過來的方法 |
| 接收者 | receiver | method 宣告中綁定的型別實例 |
| 值接收者 | value receiver | `func (t T) M()`，t 是副本 |
| 指標接收者 | pointer receiver | `func (t *T) M()`，t 是原物件指標 |
| Method Set | method set | 某型別擁有的方法集合，決定 interface 滿足 |
| 隱式滿足 | implicit interface satisfaction | 不需 `implements`，方法齊就自動是 interface 實作 |

## C.2 流程控制（Control Flow）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 延後執行 | defer | 函式結束前依 LIFO 執行的呼叫 |
| 無限迴圈 | infinite loop | `for { ... }` |
| 範圍迴圈 | range loop | `for i, v := range ...` |
| 落穿 | fallthrough | switch 中強制執行下一個 case |
| 標籤 | label | 給 break / continue / goto 的目標名稱 |
| 致命錯誤 | panic | 中斷正常流程、跑 defer、傳遞至呼叫者 |
| 復原 | recover | 在 defer 中攔截 panic |

---

## C.3 資料結構（Data Structures）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 切片 | slice | 動態長度陣列；header 含 ptr / len / cap |
| 底層陣列 | underlying array | slice 指向的固定大小儲存 |
| 容量 | capacity | slice 從 ptr 起算可容納的元素數 |
| 對映表 / 雜湊表 | map / hash map | 鍵值儲存；零值不能寫；非執行緒安全 |
| 結構 | struct | 欄位的有序集合，類似 C struct |
| 標籤 | struct tag | 欄位後反引號內的 metadata，如 `json:"name"` |
| 匿名結構 | anonymous struct | 一次性、無命名的 struct |
| 指標 | pointer | 變數的記憶體位址 |
| 字串 | string | 唯讀 byte 序列，UTF-8 編碼 |
| 字元 | rune | Unicode code point，型別為 int32 |
| 位元組 | byte | uint8 別名 |

## C.4 介面與泛型（Interface & Generics）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 介面 | interface | 一組方法簽章；用以表達行為 |
| 空介面 | empty interface / `any` | 任何型別都滿足 |
| 介面型別斷言 | type assertion | `v, ok := x.(T)` |
| 型別 switch | type switch | `switch v := x.(type)` |
| 泛型 | generics | 型別參數化函式 / 型別 |
| 型別集合 | type set | constraint 接受的型別範圍 |
| 底層型別 | underlying type | `~int` 中波浪號表達 |

---

## C.5 錯誤處理（Errors）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 錯誤 | error | `interface { Error() string }` |
| 哨兵錯誤 | sentinel error | `var ErrX = errors.New(...)` |
| 錯誤包裝 | error wrapping | 用 `fmt.Errorf("...: %w", err)` |
| 錯誤展開 | unwrap | `errors.Unwrap(err)` 取出包裝前的 err |
| 錯誤鏈匹配 | errors.Is / errors.As | 跨多層 wrap 找出特定錯誤 |
| 程式設計者錯誤 | programmer error | 不該發生的 bug，可用 panic |

## C.6 併發（Concurrency）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 協程 / 輕量執行緒 | goroutine | Go runtime 排程的輕量執行緒 |
| 通道 | channel | 型別安全的 goroutine 間 pipe |
| 緩衝通道 | buffered channel | `make(chan T, N)`，可暫存 N 個值 |
| 無緩衝通道 | unbuffered channel | `make(chan T)`，同步交付 |
| 多路選擇 | select | 對多個 channel 操作擇一執行 |
| 互斥鎖 | mutex | 序列化共享狀態存取 |
| 讀寫鎖 | RWMutex | 允許多讀單寫 |
| 等待群組 | WaitGroup | 等多個 goroutine 結束 |
| 一次執行 | sync.Once | 保證某動作執行一次 |
| 物件池 | sync.Pool | 重用物件以減 GC 壓力 |
| 原子操作 | atomic | 無鎖的單一變數原子讀寫 |
| 取消傳播 | cancellation propagation | 由 context 跨層傳遞取消訊號 |
| 競態條件 | race condition | 多 goroutine 對同一資料的非同步讀寫 |
| 競態偵測 | race detector | `go test -race`，找競態 |
| 工作竊取 | work stealing | P 從其他 P 偷 G 來執行 |
| 搶占 | preemption | runtime 強制中斷長時間執行的 goroutine |
| 排程模型 | GMP scheduler | Goroutine / Processor / Machine |

## C.7 模組與工具鏈（Modules & Tooling）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 語意化版本 | semantic versioning (SemVer) | MAJOR.MINOR.PATCH |
| 模組路徑 | module path | go.mod 第一行的 module 名稱 |
| 直接依賴 | direct dependency | 你的 code 直接 import 的 package |
| 間接依賴 | indirect dependency | 依賴的依賴 |
| 替換指令 | replace directive | go.mod 中把某依賴指到其他位置 |
| 排除指令 | exclude directive | 拒絕特定版本 |
| 撤回 | retract | 自己撤回已釋出的版本 |
| 校驗檔 | go.sum | 依賴指紋簿，保證可重現 |
| 校驗資料庫 | sum DB | 全域驗證 module 一致性的服務 |
| 私有模組 | private module | 公司內部、不走公開 proxy |
| 工作區 | go workspace (`go.work`) | 多 module 共同開發環境 |
| 廠商化 | vendoring (`vendor/`) | 把依賴複製進專案 |

## C.8 部署與運維（Deployment & Ops）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 交叉編譯 | cross compilation | 用 GOOS / GOARCH 在 A 平台編譯 B 平台 binary |
| 連結器旗標 | ldflags | `-ldflags`，用以注入版本字串、瘦身 |
| 嵌入資源 | embed | `//go:embed` 把檔案打進 binary |
| 建構標籤 | build tag | `//go:build`，條件編譯 |
| 多階段建構 | multi-stage build | Dockerfile 分 builder / runtime |
| 純靜態執行檔 | static binary | 不依賴系統共享庫，可塞 scratch image |
| 健康檢查 | health check / liveness / readiness | K8s 探活與就緒探針 |
| 優雅關閉 | graceful shutdown | 收到 SIGTERM 後完成處理中請求再退出 |
| 剖析 | profiling | pprof 收集 CPU / heap / goroutine 統計 |
| Profile 引導優化 | PGO | 用 production profile 指導編譯優化 |
| 漏洞掃描 | vulnerability scan | `govulncheck` 等工具掃 CVE |
| 結構化日誌 | structured logging | key-value 日誌，便於檢索（`log/slog`） |

## C.9 設計與架構（Design & Architecture）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| 組合 | composition | 用 has-a 取代 is-a |
| 多型 | polymorphism | Go 用 interface 達成 |
| 依賴注入 | dependency injection (DI) | 把依賴從外部傳入而非自建 |
| 控制反轉 | inversion of control (IoC) | 上層定義介面，下層實作 |
| 領域層 | domain layer | 純粹商業實體與規則 |
| 應用層 / 服務層 | service / use case layer | 編排 domain 與 repo |
| 倉儲 | repository | 隱藏儲存細節的抽象 |
| 傳輸層 | transport layer | HTTP / gRPC / CLI 入口 |
| 中介軟體 | middleware | 包覆 handler 的鏈式處理 |
| 限流 | rate limiting | 控制單位時間請求數 |
| 熔斷器 | circuit breaker | 連續失敗時短暫停止請求 |
| 健康度 | observability | log + metric + trace 三件套 |

## C.10 慣用詞（Idioms & Slang）

| 中文 | 英文 | 一句話定義 |
|---|---|---|
| Go 慣用法 | idiomatic Go | 寫得「像 Go」的風格 |
| 反模式 | anti-pattern | 看似合理但會出問題的寫法 |
| 表格驅動測試 | table-driven test | 用 slice 列出 case + 迴圈 |
| 方法集 | method set | 見 C.1 |
| 提早返回 | early return | 偵錯路徑早 return，正路保持平淺 |
| 守衛敘述 | guard clause | 檢查前置條件並提早 return |
| 哨兵值 | sentinel value | 特殊值代表特定狀態（如 `ErrNotFound`） |
| 介面汙染 | interface pollution | 過度抽象、為抽而抽的 interface |
| Pipeline | pipeline | 多 stage 用 channel 串接 |
| 扇出 / 扇入 | fan-out / fan-in | 拆散處理後合併結果 |

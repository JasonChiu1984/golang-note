# 第 2 章 基礎語法

> 把 Go 的 25 個關鍵字當作樂高，本章教你拼出基本造型。

---

## 2.1 變數宣告（Variable Declaration）

Go 提供四種宣告方式：

```go
// 1. 完整宣告：型別明確、可在 package level 用
var name string = "Amy"

// 2. 型別推論（type inference）：右值可推時，省略型別
var count = 3

// 3. 短宣告（short declaration）：只能在「函式內」用
age := 30

// 4. 多重宣告
var (
    host = "localhost"
    port = 8080
    tls  = false
)
```

### `:=` 與 `=` 的區別
- `:=` 同時做「宣告 + 賦值」，**至少要有一個新變數**。
- `=` 只是賦值，變數必須已宣告。

```go
x := 1
x, y := 2, 3   // OK：y 是新變數，x 被覆寫
x = 4          // OK：純賦值
// x := 5      // ❌ 編譯錯誤：x 已宣告，且沒有新變數
```

### Idiom：宣告即使用
Go 不允許「宣告了卻沒用」的變數（unused variable 是編譯錯誤）。
解法：要嘛刪掉、要嘛用 `_`（blank identifier）丟掉。

```go
// _, err := doWork()  // 忽略第一個回傳值
```

## 2.2 常數（Constant）

```go
const Pi = 3.14159
const (
    StatusOK    = 200
    StatusBadReq = 400
)
```

- 常數只能是**基本型別**（數字、字串、布林）。
- 常數沒有位址（`&Pi` 編譯錯誤）。
- 常數有「無型別常數」（untyped constant）特性，可以在賦值時自動轉型：
  ```go
  const N = 10              // untyped int constant
  var i int32 = N            // OK
  var f float64 = N          // OK
  ```

## 2.3 型別系統總覽（Type System）

### 整數型別（Integer Types）

| 型別 | 大小 | 範圍 |
|---|---|---|
| `int8` | 1 byte | −128 ~ 127 |
| `int16` | 2 bytes | −32,768 ~ 32,767 |
| `int32` | 4 bytes | ≈ ±2.1 × 10⁹ |
| `int64` | 8 bytes | ≈ ±9.2 × 10¹⁸ |
| `int` | 平台相依（4 或 8 bytes） | 通常 64-bit |
| `uint8` ~ `uint64` | 同上但無號 | 0 起算 |
| `uint` | 平台相依 | |
| `uintptr` | 與指標等大 | 存指標數值用，極少用到 |

> **慣例**：一般迴圈變數、長度、索引用 `int`；序列化、跨平台二進位協定才指定 `int32`、`int64`。

### 浮點數（Floating Point）
- `float32`：4 bytes，IEEE-754 單精度
- `float64`：8 bytes，IEEE-754 雙精度（**預設選它**）

```go
x := 1.0       // 預設是 float64
y := float32(1.0)
```

> ⚠️ 浮點數比較不要用 `==`，用容差：`math.Abs(a-b) < 1e-9`。

### 布林（Boolean）
`bool`：1 byte，只有 `true` / `false`，**不能轉成 int**（不像 C 那樣 `1 == true`）。

### 字串（String）
- `string` 是**唯讀的 byte 序列**（UTF-8 編碼）。
- Header 16 bytes：8 bytes 指標 + 8 bytes 長度。
- 字串相加會建新字串（不可變）；多段拼接用 `strings.Builder`。

```go
s := "Hello, 世界"
len(s)              // 13（byte 數，不是字元數）
utf8.RuneCountInString(s)  // 9（字元數）

for i, r := range s {
    fmt.Printf("%d %c\n", i, r)  // r 是 rune，i 是 byte 位置
}
```

### Byte 與 Rune（Aliases）
| 別名 | 實際型別 | 用途 |
|---|---|---|
| `byte` | `uint8` | 處理二進位資料 |
| `rune` | `int32` | 處理 Unicode code point |

### 複合型別 Header 大小（64-bit 平台）

| 型別 | 大小 | 內容 |
|---|---|---|
| `slice` | 24 bytes | ptr (8) + len (8) + cap (8) |
| `map` | 8 bytes | 指向 hash table 的指標 |
| `chan` | 8 bytes | 指向 channel 結構的指標 |
| `interface` | 16 bytes | type (8) + data (8) |
| pointer / func | 8 bytes | |

> 大多數時候不用記，但**理解「複合型別只是個 header」**很重要：你傳 slice 進函式，傳的是 24 bytes 的 header，不是底下整塊 array。

## 2.4 零值（Zero Value）

Go 的所有變數，宣告後若未賦值，**自動取零值**：

| 型別 | 零值 |
|---|---|
| 數字（int / float） | `0` |
| `bool` | `false` |
| `string` | `""`（空字串，不是 nil） |
| pointer / slice / map / chan / func / interface | `nil` |
| struct | 每個欄位各自的零值 |
| array | 每個元素各自的零值 |

```go
var i int           // 0
var s string        // ""
var p *int          // nil
var sl []int        // nil（但 len(sl) == 0，可以 append）
var m map[string]int // nil（讀 OK，寫 panic！）
```

> ⭐ Idiom：「Make the zero value useful.」
> 例：`var b bytes.Buffer` 直接可用、`sync.Mutex{}` 直接可鎖。設計自己的 struct 時也應該這樣。

## 2.5 流程控制（Control Flow）

### `if`：可帶短宣告

```go
if v, ok := m["key"]; ok {
    fmt.Println(v)
}
// v、ok 在 if 區塊外不可見
```

### `switch`：自動 break

```go
switch day {
case "Mon", "Tue":
    fmt.Println("weekday")
case "Sat", "Sun":
    fmt.Println("weekend")
default:
    fmt.Println("???")
}
```

- **不需要 `break`**（自動跳出）。
- 想要 fallthrough 行為要顯式寫 `fallthrough`。
- 可以沒有判斷對象 → 變成「鏈式 if」：
  ```go
  switch {
  case x < 0: return "neg"
  case x == 0: return "zero"
  default: return "pos"
  }
  ```
- 可以對「型別」做 switch（type switch）：
  ```go
  switch v := x.(type) {
  case int: ...
  case string: ...
  }
  ```

### `for`：唯一的迴圈

Go 沒有 `while`、`do-while`，全部用 `for`：

```go
// 1. 傳統 for
for i := 0; i < 10; i++ { }

// 2. while 風格
for x < 100 { x *= 2 }

// 3. 無限迴圈
for { /* break 才會結束 */ }

// 4. range over slice / array
for i, v := range list {
    fmt.Println(i, v)
}

// 5. range over map（順序不固定！）
for k, v := range m { }

// 6. range over channel（直到 close 才停）
for v := range ch { }

// 7. range over int（Go 1.22+）
for i := range 10 {  // i = 0..9
    fmt.Println(i)
}
```

> ⚠️ Go 1.22 之前，`for i := 0; i < 3; i++ { go func(){ println(i) }() }` 三個 goroutine 都印 `3`（共用 i）。
> **Go 1.22 起每次迭代產生新 i**，這個經典坑被修掉了。

### `defer`：函式結束前執行（LIFO）

```go
func readFile(path string) ([]byte, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, err
    }
    defer f.Close()  // 即使中途 return，也會執行
    return io.ReadAll(f)
}
```

- 執行順序：**後進先出**（LIFO）。
- 參數**在 defer 當下計算**，不是執行當下：
  ```go
  i := 0
  defer fmt.Println(i)  // 印 0
  i = 1
  ```
- 用途：解鎖、關檔案、關 DB 連線、log 結束時間。

## 2.6 `iota` 枚舉（Enumerated Constants）

`iota` 是 const 區塊中的「自動遞增計數器」，從 0 起算：

```go
type Status int
const (
    StatusNew     Status = iota  // 0
    StatusRunning                // 1（隱式延用上一行表達式）
    StatusDone                   // 2
)
```

進階技巧：
```go
type FileMode uint32
const (
    Read    FileMode = 1 << iota  // 1
    Write                          // 2
    Execute                        // 4
)

const KB = 1 << (10 * (iota + 1))  // 1024
```

> Idiom：自訂型別 + iota = 型別安全的枚舉。永遠不要用裸 `int` 當狀態碼。

## 2.7 特殊語法元素

### `init()` 函式

每個 package 可以有任意個 `init()`，在 `main()` 之前自動執行：

```go
package config

var setting Setting

func init() {
    setting = loadFromEnv()
}
```

⚠️ 慎用！理由：
- 順序不可控（同 package 多個 `init` 順序未定）。
- 難測試（測試起來就跑了）。
- 容易藏副作用。

> **建議**：寧可寫 `func Init()` 或 `func New()`，由 `main` 顯式呼叫。

### `_` blank identifier

**用途一：丟掉回傳值**
```go
_, err := io.Copy(dst, src)
```

**用途二：編譯期 interface 檢查**
```go
var _ http.Handler = (*MyHandler)(nil)
// 若 MyHandler 沒實作 ServeHTTP，這行會編譯錯
```

**用途三：side-effect import**（只跑該 package 的 `init`）
```go
import _ "github.com/lib/pq"  // 註冊 postgres driver
```

### 型別定義 vs 型別別名

```go
// 型別定義（type definition）：新型別，方法不繼承
type UserID int
var u UserID = 1
var i int = u   // ❌ 編譯錯誤：型別不同
var i int = int(u)  // OK：顯式轉型

// 型別別名（type alias）：完全等同
type ID = int
var u ID = 1
var i int = u   // ✅ OK：相同型別
```

> ⭐ 偏好「型別定義」，因為能加方法、有型別安全；別名只在重構搬遷時用。

## 2.8 註解（Comments）

```go
// 單行註解

/*
多行
註解
*/

// 文件註解：寫在 export 名稱前一行
// User 代表系統中的使用者。
type User struct { ... }
```

**慣例**：
- `// User 代表...` 註解第一個字應該是該名稱。
- `go doc User` 會把註解當文件顯示。
- Package 註解寫在 `package xxx` 上方，僅一個檔案需要。

## 2.9 Go 1.22 / 1.21 重要新特性

### Go 1.21
- `min`、`max`、`clear` 內建函式
  ```go
  m := min(3, 1, 2)  // 1
  M := max(3, 1, 2)  // 3
  clear(slice)        // 全部歸零；clear(map) 全部刪除
  ```
- `slices`、`maps` 標準庫套件（取代 `golang.org/x/exp/...`）
- Profile-guided optimization（PGO）正式化

### Go 1.22
- ⭐ **range over int**：`for i := range 10`
- ⭐ **loop variable per iteration**：解決 closure 抓到共用 i 的經典坑
- 新版 `net/http` ServeMux：支援 method + path pattern
  ```go
  mux.HandleFunc("GET /users/{id}", handler)
  ```

## 2.10 Idiom 與 Anti-pattern

### ✅ Idiom
- **短變數名**：`i`, `r`, `buf`, `ctx`、`err`、`ok`。
- **`if err != nil` 早 return**，不要嵌套。
- **`for i := range slice`** 比 `for i := 0; i < len(slice); i++` 好讀。
- **零值有意義**：自訂 struct 設計成 `var x MyType` 即可用。

### ❌ Anti-pattern
- 命名 `userServiceImpl`、`AbstractFactoryHelper`：Java 來的人最常犯。
- `for ... if err != nil { panic(err) }` 在 library 裡 panic。
- 在 package level 用 `:=`（編譯錯誤，只能用 `var`）。
- 變數命名長到 `numberOfRetriesAfterFirstAttempt`。

---

## 重點回顧

- 四種變數宣告，函式內愛用 `:=`，package level 用 `var`。
- 25 個關鍵字、18+ 個基本型別；零值要懂、要善用。
- `if` 帶短宣告、`switch` 自動 break、`for` 是唯一迴圈、`defer` 用得好。
- `iota` 做枚舉、`_` 丟值、`init` 慎用。
- Go 1.22 修了 loop variable 經典坑、加了 range over int。

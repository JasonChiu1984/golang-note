1. 依賴供應鏈治理缺少獨立 static gate。
   - 風險：`go list -m -u all`、`govulncheck ./...` 與 module integrity 流程只散落在 README / chapter / CI quality gate 文字中，缺少單一 checker 固定。
   - 建議：新增 `scripts/check-dependency-governance-contract.mjs`，固定 root module 與 `production-api-worker` 都保留 `go mod tidy`、`go mod verify`、`go list -m -u all`、`govulncheck ./...` 與離線處理邊界。

2. Makefile / CI 尚未提供 dependency governance 的專用入口。
   - 風險：維護者只能從 CI quality gate 間接知道依賴治理條款，無法用單一命令檢查相關文件與 workflow 是否漂移。
   - 建議：新增 `dependency-governance-check` target，並在 `.github/workflows/ci.yml` 加入 `Check dependency governance contract`。

3. Contract gate inventory 需跟隨新增 checker 前進。
   - 風險：新增 checker 後若 inventory 仍停在 31 個 root contract checker，會造成 checker 數量、CI 呼叫清單與教材敘述漂移。
   - 建議：將 inventory 基準更新為 32 個 root contract checker，並同步 README、production README、API contract、OpenAPI、章節、Cheatsheet 與整合視覺課程。

## Executive Summary

教材已具備完整 Go 語法、專案架構、API contract、request correlation、shutdown、migration、效能、ReleaseNote 與 CI release gate。以專案開發深度與廣度來看，已從入門教材提升到可作為 junior-to-mid backend engineer 的實務訓練材料。

本輪主要缺口不在語法，而在部署驗證閉環：`v1.0.24` 已新增 `.github/workflows/ci.yml` 與 Docker build job，但 Docker build 只能證明 image 可建置，不能證明 Compose stack 中的 Postgres、migration、API、readiness、worker 與 metrics 能一起啟動並回應。

## 需要更新的部分

| 優先級 | 缺口 | 建議修正 | 驗證方式 |
|---|---|---|---|
| P1 | Docker job 只 build image，不驗證服務是否真的可用 | 新增 host 端 smoke script，避免在 distroless runtime image 內加入 curl/shell | `docker compose up -d --build && make compose-smoke` |
| P1 | CI 未執行 Compose 端到端流程 | Docker job build 後啟動 Compose stack，跑 smoke，失敗輸出 logs，最後清理 volume | GitHub Actions `docker-build` job |
| P2 | README 與章節只寫 `docker compose up --build`，驗收條件不夠明確 | 補上 `/livez`、`/readyz`、job create/read、metrics 的明確 gate | `rg "compose-smoke|Compose smoke" ...` |
| P2 | 整合視覺課程未連到 smoke script | 在 production project walkthrough 加入 script 入口與指令 | 同步 `docs/index.html` |

## 修正策略

1. 新增 `production-api-worker/scripts/compose-smoke.sh`。
2. 新增 `make compose-smoke`，讓本機與 CI 共用同一入口。
3. 更新 `.github/workflows/ci.yml`，Docker job 改為 build + compose up + smoke + logs + cleanup。
4. 更新 README、production README、第 9 / 11 章、Cheat Sheet、康乃爾筆記與整合 HTML。
5. 複製 `圖解筆記3-4整合/golang-complete-visual-course.html` 到 `docs/index.html`。
6. 版本標註為 `v1.0.25`，並建立更新紀錄與 changelog。

## 風險備註

| 風險 | 說明 | 處理 |
|---|---|---|
| 本機 Docker daemon 未啟動 | 本環境可能無法實際跑 Compose | 若受限，保留為環境阻擋，不標示已通過 |
| distroless image 無 curl/shell | 不適合把 healthcheck 寫進容器內 | 使用 host 端 smoke script |
| `curl` 不存在 | smoke script 會 fail fast | 文件需保留 curl 前置條件 |
| 網路 / module proxy | production module 首次下載依賴可能受限 | 使用 repo-local cache 或在 CI 跑完整流程 |

## 結論

本教程目前專案開發深度已足夠，下一個最小且高價值的補強點是把 Docker Compose runtime smoke gate 納入 repo 與 CI。完成後，release gate 將從「可建置」提升到「可啟動、可接流量、可處理基本 job、可暴露 metrics」。

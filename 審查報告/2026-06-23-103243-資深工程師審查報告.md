## 結論

教程的專案開發深度與廣度已符合中高階實務教學定位：HTTP API、worker queue、Postgres repository、migration、OpenAPI、Prometheus、OpenTelemetry、Docker Compose、CI quality gate、release artifact chain 與 GitHub Pages publishing 都有對應章節與 static contract gate。這輪不建議擴張新功能，而應把既有 observability shutdown 行為納入正式 contract gate。

主要缺口是 trace provider shutdown 目前已在 `production-api-worker/internal/observability/observability.go` 以 `context.WithTimeout(ctx, 3*time.Second)` bounded shutdown，且 `cmd/api-worker/main.go` 會在 process exit 時呼叫 `obs.Shutdown(context.Background())`，但缺少獨立 Go contract test、root checker、Makefile target、CI step 與教材入口。這會讓後續重構 exporter、OTLP/stdout trace pipeline 或 api-worker lifecycle 時，有機會把 telemetry flush 邊界改成無 deadline 或漏掉 shutdown hook。

官方 Go Release History 於本次審查確認 Go 1.26 最新 patch 仍為 go1.26.4，Go 1.25 最新 patch 仍為 go1.25.11，發布日皆為 2026-06-02；本輪不需要更新 ReleaseNote patch token。

3. 新增 `scripts/check-trace-shutdown-contract.mjs`，同步檢查 observability code、api-worker exit hook、Go test、README、API contract、OpenAPI、章節、Cheat Sheet、整合視覺課程、Makefile 與 GitHub Actions。

5. 將 `.github/workflows/ci.yml` 補上 `Check trace shutdown contract`，並讓 production contract job 跑 observability focused test。

## 1. 整體判斷

本教程目前已符合「專案開發深度與廣度」要求：主線包含 Go 語法、資料結構、併發、project-concurrent-crawler、production-api-worker、API contract、observability、lifecycle、DB pool、migration contract、測試與部署 gate。

本輪重新審查後，最高優先缺口不在後端範例程式，而是在 Release Note 教材的正式發布狀態。前序產物已補齊 Go 1.2-1.26 Release Note 的官方段落解析與細節重寫，但工作樹仍停留在未提交狀態，且 `docs/ReleaseNote/` 與根目錄 `ReleaseNote/` 出現內容漂移。若直接推送 Pages，讀者可能看到舊版報告，無法取得 Tools、Ports、minor changes、new package 與 Patch Revisions 的完整工程化解讀。

官方 release history 於本輪確認 Go 1.26.3 仍是 Go 1.26 最新 patch，Go 1.25.10 也於 2026-05-07 發布，兩者都包含 security fixes 與多套件 bug fixes；教材繼續以 Go 1.26.3 作為 2026-05 主基準是合理的。

## 3. 主要缺失

### P1 - ReleaseNote 官方段落細節重寫尚未正式發布

`scripts/generate-go-release-notes.mjs` 與 25 份 `ReleaseNote/go1.x-release-note.html` 已包含官方段落細節重寫、Tools、Ports、minor changes 與新 package rows，但 `VERSION` 與 `CHANGELOG.md` 仍停在 v1.0.20。這會造成 repo 狀態、版本紀錄與實際內容不一致。

| 影響 | 風險 |
|---|---|
| ReleaseNote 頁面已變更但未標版 | 後續 reviewer 無法知道哪個版本開始補齊官方段落細節 |
| Generator 已改但缺少更新紀錄 | 未來重新產生頁面時難以追蹤資料模型與官方解析規則 |
| Go 1.21-Go 1.26 rows 新增但未說明 | 讀者不知道 Tools / Ports / minor changes 已納入升級 gate |

### P1 - `docs/ReleaseNote/` 與根目錄 `ReleaseNote/` 漂移

目前 `ReleaseNote/go1.26-release-note.html` 與 `docs/ReleaseNote/go1.26-release-note.html`、`ReleaseNote/index.html` 與 `docs/ReleaseNote/index.html` 內容不一致。GitHub Pages 通常由 `docs/` 供應，因此只更新根目錄報告不足以交付。

## 4. 需要更新的部分

| 發布 | 升級到 v1.0.21，新增 CHANGELOG、更新清單、更新紀錄、Git tag 並推送 |

## 5. 驗證建議

| 驗證項 | 指令 |
|---|---|
| Generator 語法 | `node --check scripts/generate-go-release-notes.mjs` |
| ReleaseNote 官方段落 | `rg -n "官方段落細節重寫摘要|Tools|Ports|Minor changes to the library|go1.26.3" ReleaseNote docs/ReleaseNote` |
| ReleaseNote 數量 | `find ReleaseNote -maxdepth 1 -type f -name 'go1.*-release-note.html' \| wc -l` |
| Pages ReleaseNote 數量 | `find docs/ReleaseNote -maxdepth 1 -type f -name 'go1.*-release-note.html' \| wc -l` |
| 根目錄與 Pages 同步 | `for f in ReleaseNote/*.html; do cmp -s "$f" "docs/$f" || exit 1; done` |
| docs 入口連結 | `rg 'href="ReleaseNote/index.html"' docs/index.html` |
| Root module | `TMPDIR=$PWD/.tmp GOCACHE=$PWD/.gocache GOMODCACHE=$PWD/.gomodcache GOFLAGS='-ldflags=-linkmode=external' go test ./... -count=1` |
| Production module | `cd production-api-worker && TMPDIR=$PWD/.tmp GOCACHE=$PWD/.gocache GOMODCACHE=$PWD/.gomodcache GOFLAGS='-ldflags=-linkmode=external' go test ./... -count=1` |
| 格式檢查 | `git diff --check` |

## 6. 風險註記

- 本輪使用官方 Go release history 與 Go 1.26 release note 作為版本狀態依據；若 go.dev 之後發布 Go 1.26.4 或 Go 1.27，需重新跑官方來源檢查。
- 本輪整理的是 release-note 教材與 Pages 同步，不宣稱完成本地 Go 1.26 toolchain 實測升級。
- 若推送時 DNS 或 GitHub 網路不穩，需清楚回報 push 是否成功，不能把本地 tag 視為已發布。

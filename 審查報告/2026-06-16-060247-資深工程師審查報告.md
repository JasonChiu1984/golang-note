## 需要修正的缺口

### P1 - 語法 SVG 流程圖品質門檻未納入正式 contract gate

目前 `scripts/check-syntax-flow-svg.mjs` 能檢查 25 個語法流程圖、標準流程圖符號與 SVG metadata，但它不是 `check-*-contract.mjs`，因此不會被 contract inventory gate 自動盤點，也沒有 `make syntax-flow-svg-check` 與 `.github/workflows/ci.yml` 的正式 release gate。建議新增 `scripts/check-syntax-flow-svg-contract.mjs`，用它包住既有品質檢查，並同時固定 README、production README、API contract、OpenAPI、第 7 / 9 / 11 章、Cheatsheet、整合視覺課程、Makefile 與 CI 入口。

### P2 - Contract gate inventory 需跟著新 checker 前進

新增 syntax flow SVG contract 後，root contract checker 會從 28 個增加為 29 個。`scripts/check-contract-gate-inventory-contract.mjs`、`scripts/check-docs-publishing-contract.mjs`、OpenAPI 與文件中的 inventory 數量都需同步更新，避免 checker 數量與 release 文件不一致。

### P2 - docs/index.html 需由整合課程來源重新同步

步驟四要求將 `圖解筆記3-4整合/golang-complete-visual-course.html` 同步到 `docs/index.html`。本輪會修改整合課程中的 gate 矩陣，因此需重新同步並執行 `fix-docs-index-links.mjs --sync-source` / `--check` 與 `check-html-home-links.mjs`。

## 建議更新清單

1. 新增 `scripts/check-syntax-flow-svg-contract.mjs`，固定語法 SVG 流程圖 contract。
2. 在 `production-api-worker/Makefile` 新增 `syntax-flow-svg-check`。
3. 在 `.github/workflows/ci.yml` 新增 `Check syntax flow SVG contract`。
4. 將版本推進到 `v1.0.60`，並將 contract inventory 從 28 個更新到 29 個。
5. 同步 README、production README、API contract、OpenAPI、第 7 / 9 / 11 章、Cheatsheet 與整合視覺課程。
6. 將整合視覺課程重新同步到 `docs/index.html`。
7. 建立本次「內容需要更新的部分」與「更新資料」並完成 tag / push。

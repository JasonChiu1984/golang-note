## 1. Overview

本教程已具備一般 Go 入門教材少見的 production 專案深度：語法、標準庫、concurrency、testing、benchmark、HTTP API、worker queue、Postgres migration、OpenAPI、Prometheus、OTLP、pprof、rate limit、CI 與 Docker smoke gate 均有教材與可執行範例。

本輪最高價值缺口不是新增大型功能，而是補齊 production lifecycle 與入口限速的部署信任邊界：`api-worker` 必須同時監聽 `SIGINT` / `SIGTERM`，且 rate limit 不應無條件信任外部送來的 `X-Forwarded-For`。

## 2. Architecture

| 層級 | 現況 | 缺口 | 建議 |
|---|---|---|---|
| Process lifecycle | 已有 readiness draining、HTTP shutdown、queue drain | 若只處理 local interrupt，Docker / Kubernetes 常見 `SIGTERM` 可能繞過 graceful shutdown | 新增 `monitoredSignals()` 與 `TestMonitoredSignalsContract` |
| Rate limit key | 已有 per-client IP fixed window | 無條件信任 `X-Forwarded-For` 會讓外部 client 偽造 key | 新增 `TRUSTED_PROXY_CIDRS`，只信任指定 CIDR 來源 |
| Configuration | 已集中驗證 port、queue、DB、pprof、rate limit | proxy CIDR 若拼錯不可 silent fallback | 啟動時解析 CIDR，錯誤 fail fast |
| Release gate | 已有 OpenAPI / pprof / rate limit / OTLP checks | shutdown 與 trusted proxy 邊界需要納入 CI 與文件 gate | 更新 Makefile、CI、檢查腳本、README、runbook、章節 |

## 3. Configuration

| Env | 預設 | 行為 |
|---|---|---|
| `RATE_LIMIT_REQUESTS_PER_MINUTE` | `120` | 每個 client IP 每分鐘業務 endpoint 呼叫上限 |
| `TRUSTED_PROXY_CIDRS` | 空字串 | 空值時不信任 `X-Forwarded-For`；CIDR 命中時才採用第一個 forwarded IP |

## 5. Troubleshooting

| 症狀 | 可能原因 | 處置 |
|---|---|---|
| Docker / Kubernetes stop 時沒有 draining | 未監聽 `SIGTERM` | 確認 `TestMonitoredSignalsContract` 通過 |
| 不同 client 仍被同一 key 限速 | `TRUSTED_PROXY_CIDRS` 未包含實際代理來源 | 檢查代理 `RemoteAddr` 與 CIDR 設定 |
| 外部可用 `X-Forwarded-For` 繞過限速 | 服務錯誤信任未授權來源 | 保持 `TRUSTED_PROXY_CIDRS` 空值或只填內部代理 CIDR |
| 設定 `TRUSTED_PROXY_CIDRS=not-a-cidr` 仍啟動 | config validation 漏失 | 應由 config test 與 rate-limit check 阻擋 |

## 6. Best Practices

| 原則 | 說明 |
|---|---|
| lifecycle contract 要可測 | 文件寫 graceful shutdown 不夠，signal set 也要有測試固定 |
| forwarded header 必須有信任邊界 | `X-Forwarded-For` 只有在 trusted proxy 來源才可信 |
| health endpoint 不限速 | `/livez`、`/readyz` 不應被業務流量誤傷 |
| release artifact 要一致 | README、OpenAPI、API contract、runbook、CI、Pages 與 tag 應同版收斂 |

## 7. Risk Notes

| 風險 | 狀態 |

| 分散式 rate limit / gateway policy | 超出本輪最小安全修正，可獨立成後續章節 |

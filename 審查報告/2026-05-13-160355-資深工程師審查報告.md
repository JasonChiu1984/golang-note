## 3. 主要缺失

### P1 - Go 1.20 Release Note 缺少效能比較矩陣

Go 1.20 官方 release note 明確包含多個效能或成本訊號，但原頁面主要散落在 coverage / added / compat 表格中。對工程團隊而言，升級 Go 版本時需要的是「升級前後差異、官方數字、受影響場景、驗證方式」。

| 缺口 | 風險 |
|---|---|
| 沒有集中列 Runtime / GC、PGO、build speed 數字 | 讀者容易只看到功能，不知道升級可期待的性能收益 |
| 沒有集中列 crypto 成本 | TLS / signing / legacy RSA workload 可能升級後 CPU 成本上升而未先 benchmark |
| 沒有 runtime metrics histogram tradeoff | observability dashboard 可能忽略 memory footprint 與精度變化 |
| `docs/ReleaseNote` 未同步 | GitHub Pages 入口看不到本地 ReleaseNote 的最新修正 |

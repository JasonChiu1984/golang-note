# A1. 語言規範速覽 — 康乃爾筆記

> **日期**：2026-05 ｜ **版本基準**：Go 1.22 ｜ **學習目標**：精確理解 Go 語言的底層規範細節

---

| 🔑 線索欄（關鍵字 / 問題） | 📝 筆記欄（詳細內容） |
|:--|:--|
| **標識符 (Identifiers) 命名規則** | 只能由**字母、數字、底線**組成。<br>❌ 不能以數字開頭。<br>✅ `_` (單一底線) 是合法的空白標識符 (Blank Identifier)。 |
| **可見性規則 (Exported)** | Go 沒有 `public` / `private` 關鍵字。<br>首字母大寫：公開 (Exported)，其他套件可見。<br>首字母小寫或底線：私有 (Unexported)，僅當前套件可見。 |
| **25 個關鍵字** | `break`, `case`, `chan`, `const`, `continue`, `default`, `defer`, `else`, `fallthrough`, `for`, `func`, `go`, `goto`, `if`, `import`, `interface`, `map`, `package`, `range`, `return`, `select`, `struct`, `switch`, `type`, `var` |
| **預先宣告標識符** | 包含內建型別 (`int`, `string`, `bool`, `error`...)、常數 (`true`, `false`, `nil`)、內建函式 (`make`, `len`, `append`, `panic`...)。<br>⚠️ 它們**不是關鍵字**，技術上你可以宣告變數遮蔽它們（極度不推薦）。 |
| **數字字面量 (Numeric Literals)** | 十進位：`42`<br>二進位：`0b1010` (開頭 `0b`)<br>八進位：`0o755` 或 `0755`<br>十六進位：`0xFF` (開頭 `0x`)<br>底線分隔（增加可讀性）：`1_000_000` |
| **字串字面量 (String Literals)** | Interpreted string: `"hello\n"` (雙引號，解釋跳脫字元)<br>Raw string: `` `raw\nstring` `` (反引號，不解釋跳脫字元，可跨行) |
| **常數 (Constants)** | 在編譯期就決定的值。只能是字元、字串、布林或數字。<br>Go 的常數具有**無型別 (Untyped)** 特性，`const x = 42` 可以直接賦值給 `int64` 或 `float64` 而不需強制轉型。 |
| **作用域 (Scope) 的三個層級** | 1. **Universe block**：所有預先宣告標識符（如 `int`, `true`）<br>2. **Package block**：宣告在所有函式外的變數、常數、型別<br>3. **Local block**：函式內部、`if`/`for`/`switch` 區塊內部 |
| **Shadowing (遮蔽) 陷阱** | 內層作用域宣告了和外層同名的變數，會「遮蔽」外層。<br>常發生在使用 `:=` 時，不小心遮蔽了外層的 `err` 變數。 |

---

## 🗒️ 摘要

> Go 的語言規範極度精簡，僅有 25 個關鍵字。大小寫決定可見性是其招牌特色。必須清楚認知預先宣告標識符與關鍵字的差異，善用底線分隔提升數字字面量可讀性，並隨時警惕短宣告 `:=` 可能造成的 Variable Shadowing 陷阱。

# Golang 學習筆記 — 康乃爾筆記法索引

> **版本基準**：Go 1.26.3
>
> 康乃爾筆記用於複習與自測，版本訊號需與主教材一致；若範例 module 仍保留 `go 1.22`，代表相容層，不代表教材只涵蓋 Go 1.22。

> **康乃爾筆記法格式說明**：
> - 左欄（線索欄）：關鍵字、問題、提示 — 用來自我測驗
> - 右欄（筆記欄）：詳細說明、程式碼範例
> - 底部（摘要欄）：本章核心概念一句話精華

## 🎯 康乃爾筆記法使用說明

1. **第一遍閱讀**：照順序讀右欄（筆記欄）
2. **第二遍複習**：遮住右欄，只看左欄（線索欄），自問自答
3. **第三遍鞏固**：讀底部摘要，確認掌握核心概念
4. **實戰前**：快速掃過線索欄，確認沒有盲點

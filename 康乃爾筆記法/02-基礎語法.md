# 02. 基礎語法 — 康乃爾筆記

> **日期**：2026-05 ｜ **版本基準**：Go 1.22 ｜ **學習目標**：掌握 Go 核心語法心智模型

---

| 🔑 線索欄（關鍵字 / 問題） | 📝 筆記欄（詳細內容） |
|:--|:--|
| **`:=` vs `var` 的選擇** | `:=`：函式內短宣告（最常用），自動推斷型別<br>`var`：package 層級、或需要明確型別、零值宣告時使用 |
| **Go 整數型別有哪些？** | `int8`(1B) `int16`(2B) `int32`(4B) `int64`(8B) `int`(平台相依)<br>對應 `uint` 系列。**日常用 `int`，需精確控制才用 `int64`** |
| **`float32` vs `float64`** | `float64` 是預設浮點型別（精度更高，硬體原生支援）<br>`float32` 只在 GPU/圖形運算等有特殊需求時使用 |
| **`string` 的本質** | 唯讀的 byte sequence（不是 rune sequence）<br>Header = 16 bytes（ptr + len）；`len(s)` 回傳 byte 數，不是字元數 |
| **`byte` 和 `rune` 的差異** | `byte` = `uint8`：原始位元組<br>`rune` = `int32`：Unicode code point（一個字元） |
| **複合型別在記憶體中的大小** | `slice`：24B (ptr+len+cap)<br>`map`：8B (pointer)<br>`channel`：8B (pointer)<br>`interface`：16B (type ptr + data ptr) |
| **`if` 的短宣告語法** | `if v, ok := m["key"]; ok { }` — v 和 ok 的作用域只在 if block 內 |
| **`switch` 和其他語言的差異** | **不需要 break**（預設不 fallthrough）<br>需要 fallthrough 就明確寫 `fallthrough`<br>case 可以是多個值：`case "a", "b":` |
| **Go 只有一種迴圈是什麼？** | `for`，但有四種形式：<br>傳統：`for i:=0; i<n; i++`<br>while：`for condition { }`<br>無限：`for { break }`<br>遍歷：`for i, v := range slice` |
| **`defer` 的三個關鍵特性** | 1. 函式結束時才執行（不是 block 結束）<br>2. 多個 defer 按 LIFO 順序<br>3. 參數在宣告時立即估值（不是執行時） |
| **`iota` 怎麼用？** | 在 `const` block 中，`iota` 從 0 開始，每行遞增 1<br>常見模式：`StatusNew Status = iota`（0, 1, 2...）<br>偏移：`iota + 1`；位元：`1 << iota` |
| **`init()` 的用途與限制** | 在 `main()` 前自動執行，可有多個<br>**不推薦濫用**：難以測試、執行順序不明確<br>適合：driver 註冊、全域 regexp 編譯 |
| **blank identifier `_` 有哪三個用途？** | 1. 忽略回傳值：`_, err := fn()`<br>2. 只 import 副作用：`import _ "net/http/pprof"`<br>3. 編譯期 interface 檢查：`var _ io.Writer = (*T)(nil)` |
| **型別定義 vs 型別別名** | `type UserID int64`：全新型別，不能直接與 `int64` 互換<br>`type ID = int64`：完全相同，可互換，常用於漸進重構 |
| **`const` 和 `var` 的限制** | `const` 只能是基本型別（bool/string/數字），不能是 slice/map<br>編譯時計算，無執行期開銷 |

---

## 🗒️ 摘要

> Go 的型別系統明確、零魔法：用 `:=` 短宣告，`defer` 做資源清理，`iota` 定義枚舉，`for range` 遍歷一切。記住 `string` 是 byte sequence（不是字元序列），`len("中文")` = 6 而非 2。

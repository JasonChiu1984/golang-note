## 1. 更新摘要

本次更新把 OpenTelemetry collector 從「Compose 中存在」提升為可重跑的 OTLP collector contract。教材現在固定本地 OTLP gRPC receiver、debug exporter、Compose endpoint、runbook、README、章節、整合 HTML 與 CI gate。

## 4. Release Notes

- OpenTelemetry collector 本地 contract 以 `debug exporter` 作為教學預設，避免依賴額外 trace backend。
- 正式環境仍需依平台替換 exporter，並補上 Tempo / Jaeger / OTLP backend、取樣率、保存期限與敏感資料策略。
- 本輪未改動 business API 行為，屬 observability deployment gate 強化。

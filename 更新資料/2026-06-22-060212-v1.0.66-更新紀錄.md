## 更新摘要

- 新增 Service transaction boundary contract gate。
- 新增 `scripts/check-service-transaction-boundary-contract.mjs`，固定 `CreateJob` 的 transaction isolation、commit 後 enqueue、queue-full failed 回寫、文件與 CI 入口。
- 新增 `TestServiceTransactionBoundaryContract`，讓 service transaction boundary 有可直接執行的 Go contract test。
- `production-api-worker/Makefile` 新增 `service-transaction-boundary-check`，`make ci-contract` 納入 `TestServiceTransactionBoundaryContract`。
- `.github/workflows/ci.yml` 新增 `Check service transaction boundary contract`，production contract job 納入 `TestServiceTransactionBoundaryContract`。
- README、production README、API contract、OpenAPI、第 7 / 9 / 11 章、進階 Cheat Sheet、整合視覺課程同步 Service transaction boundary contract 說明。
- Contract gate inventory 從 34 個 root contract checker 更新為 35 個。
- `VERSION`、`CHANGELOG.md`、version-sensitive contract checks 更新為 `v1.0.66`。
- `docs/index.html` 已由 `圖解筆記3-4整合/golang-complete-visual-course.html` 同步並套用 GitHub Pages link fix。

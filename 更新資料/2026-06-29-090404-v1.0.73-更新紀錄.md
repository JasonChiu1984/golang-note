## 更新摘要

本次更新將既有 Prometheus scrape config、alert rules 與 Compose monitoring profile 從一般 config gate 升級為正式 Prometheus config contract gate。此切片不新增 runtime feature，重點是把已存在的 monitoring artifact 納入 root `scripts/check-*-contract.mjs` inventory、Makefile、GitHub Actions、教材章節與 release artifact chain。

## 修改內容

1. 新增 `scripts/check-prometheus-config-contract.mjs`
   - 固定 `configs/prometheus/prometheus.yml` 的 `scrape_interval`、`evaluation_interval`、`rule_files`、`production-api-worker` scrape job、`/metrics` path、`api:8080` target 與 `environment: local-compose` label。
   - 固定 `configs/prometheus/production-api-worker-alerts.yml` 的 5xx、critical 5xx、queue depth、worker latency 與 metrics missing alert rules。
   - 固定 Compose `monitoring` profile、Prometheus config/rules mount、`9090` port、runbook、README、章節、Cheat Sheet、整合視覺課程、Makefile 與 CI 入口。
   - 明確保留 `API_KEY` 啟用時的 scrape auth 風險：正式環境需用 Bearer token、bearer token file、secret mount 或平台原生 scrape auth，不把 secret 寫入 repo。

2. 更新 release gate wiring
   - `production-api-worker/Makefile` 的 `prometheus-check` 現在同時執行 `scripts/check-prometheus-config.mjs` 與 `scripts/check-prometheus-config-contract.mjs`。
   - `.github/workflows/ci.yml` 新增 `Check Prometheus config contract`。
   - root contract checker inventory 從 41 個更新為 42 個。

## 1. 修改摘要

本版補上 `production-api-worker` 的 Shutdown signal contract 與 trusted proxy client IP 邊界。教材描述的 graceful shutdown 不只適用 local Ctrl+C，也能明確涵蓋 Docker / Compose / Kubernetes rolling deploy 常用的 `SIGTERM`；rate limit 也不再無條件信任外部送入的 `X-Forwarded-For`。

## 6. 風險註記

- 本版固定應用程式會接收 `SIGTERM`，但正式部署仍需設定 termination grace period 與 LB / ingress readiness policy。
- 如果 worker 任務可能超過 queue drain timeout，應另設補償任務、dead-letter queue 或可重入工作設計。
- shutdown signal contract 不取代 queue shutdown safety、request timeout 與 retry cancellation 測試；這些 gate 應一起保留。

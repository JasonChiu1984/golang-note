## 更新摘要

本次更新將既有 Request decoding behavior 升級為正式 static gate。`POST /jobs` 的 malformed JSON、unknown field、trailing JSON value 與空白 `name` 都必須穩定回 `400 invalid_input`，並由 Go contract test、Node static check、Makefile、GitHub Actions、OpenAPI、API contract、README、章節與 GitHub Pages 首頁共同固定。

## 更新摘要

本次版本將 `production-api-worker` 的 worker failure 行為提升為正式 contract gate。worker processor 成功與失敗都必須記錄 processing duration，成功結果標示為 `success`，失敗結果標示為 `failed`，避免 worker failure 只留在 log 或人工閱讀程式碼中。

## 修改內容

| 類型 | 修改 |
|---|---|
| 測試 | 新增 `TestWorkerFailureResultContract`，固定 success / failed result 與 duration 行為。 |
| 靜態檢查 | 新增 `scripts/check-worker-failure-contract.mjs`。 |
| CI / Makefile | 新增 `make worker-failure-check` 與 GitHub Actions `Check worker failure contract`。 |
| 文件 | README、production README、API contract、第 7 / 11 章、Cheat Sheet、整合視覺課程加入 Worker failure contract gate。 |
| 版本 | `VERSION`、`CHANGELOG.md`、OpenAPI、API contract 與既有 contract check 版本標記更新至 `v1.0.42`。 |
| Pages | 重新由 `圖解筆記3-4整合/golang-complete-visual-course.html` 同步 `docs/index.html`。 |

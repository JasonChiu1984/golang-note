## 行為變更

`production-api-worker` 的錯誤回應由：

```json
{"error":"invalid input"}
```

改為：

```json
{"error":{"code":"invalid_input","message":"invalid input"}}
```

這讓 client 能依穩定 `error.code` 做分支，而不是依自然語言訊息判斷。

## 驗證紀錄

| 指令 | 結果 |
|---|---|
| `git diff --check` | 通過 |
| `go test ./examples -count=1` | 通過，無測試檔 |
| `GOFLAGS='-ldflags=-linkmode=external' go test ./project-concurrent-crawler/... -count=1` | 通過 |
| `GOFLAGS='-ldflags=-linkmode=external' go test ./... -count=1` | 通過 root module 測試 |
| `go test ./internal/api -run 'Test.*Contract' -count=1` | 受限於離線環境，無法下載 Prometheus / OpenTelemetry / pgx 間接依賴 |

> 備註：`project-concurrent-crawler` 使用預設 linker 時仍會遇到既有 macOS `dyld ... missing LC_UUID load command` 問題；改用外部 linker 後通過，表示本輪文件與 root module 範例未新增該類失敗。

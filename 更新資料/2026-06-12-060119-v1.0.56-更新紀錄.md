## 更新摘要

本版將既有 Startup configuration fail-fast 行為升級為正式 static gate。`PORT`、`QUEUE_SIZE`、`WORKERS` 與 `OTEL_EXPORTER_OTLP_ENDPOINT` 不再只靠 config unit tests 與文件敘述維護，而是由 root checker、Makefile、GitHub Actions、API contract、OpenAPI、章節、Cheat Sheet 與整合視覺課程共同固定。

官方 Go 版本來源於本輪重新確認：`go.dev/VERSION` 顯示 `go1.26.4`，Go Release History 顯示 `go1.26.4` 與 `go1.25.11` 於 2026-06-02 發布。因此教材基準維持 `Go 1.26.4`，本輪不更新 Go patch baseline。

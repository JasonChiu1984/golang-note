## 更新摘要

本次依照資深工程師審查結果，將 HTTP API latency metrics 升級為正式 API latency metrics contract gate。`production-api-worker` 現在會以 `api_request_duration_seconds` histogram 記錄 HTTP request latency，並用 `route`、`method`、`status` labels 與既有 `api_requests_total` counter 對齊，讓 Prometheus SLO、alert 與 incident review 可直接觀測 API handler 延遲。

## 主要修改

- 新增 `scripts/check-api-latency-metrics-contract.mjs`。
- `production-api-worker/internal/observability/observability.go` 新增 `RequestDuration` histogram 與 `ObserveHTTPRequestDuration`。
- `production-api-worker/internal/api/handler.go` 的 metrics middleware 會觀測 request duration，並保留既有 `api_requests_total`。
- `production-api-worker/internal/api/handler_test.go` 新增 `TestAPILatencyMetricsContract`。
- `production-api-worker/Makefile` 新增 `api-latency-metrics-check`。
- `.github/workflows/ci.yml` 新增 `Check API latency metrics contract`，並將 `TestAPILatencyMetricsContract` 納入 production contract job。
- README、production README、API contract、OpenAPI、第 7 / 9 / 11 章、Cheatsheet、整合視覺課程已同步 API latency metrics contract。
- Contract gate inventory 從 33 個 root contract checker 更新為 34 個。
- `docs/index.html` 已由 `圖解筆記3-4整合/golang-complete-visual-course.html` 重新同步。

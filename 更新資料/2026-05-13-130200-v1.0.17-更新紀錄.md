## 更新摘要

本輪依資深工程師審查報告補齊 `production-api-worker` 的 startup configuration contract。服務現在會集中讀取並驗證 `PORT`、`QUEUE_SIZE`、`WORKERS`、`DATABASE_URL` 與 `OTEL_EXPORTER_OTLP_ENDPOINT`，錯誤的必要啟動設定會 fail fast，不再 silent fallback 成預設值。

## 風險與待補

- `production-api-worker go test ./...` 需外部 module cache 或可連線到 `proxy.golang.org`；本輪只把 DNS/module 下載限制記錄為環境 gate，未標示 full production-api-worker 測試已通過。
- 本輪未改動 API schema、error envelope、worker queue 行為或 retry 行為，主要變更集中在啟動設定與文件。

## 修改摘要

- 新增 `production-api-worker/scripts/compose-smoke.sh`，以 host 端 `curl` 驗證 Compose stack 的 `/readyz`、`/livez`、job create/read 與 `/metrics`。
- `production-api-worker/Makefile` 新增 `compose-smoke` target。
- `.github/workflows/ci.yml` 的 Docker job 改為 build + Compose up + smoke + failure logs + cleanup。
- README、production README、第 9 / 11 章、Cheat Sheet、康乃爾筆記與整合 HTML 同步補上 Compose smoke gate。
- `VERSION` 更新為 `v1.0.25`，`CHANGELOG.md` 新增版本紀錄。
- `docs/index.html` 由 `圖解筆記3-4整合/golang-complete-visual-course.html` 重新複製產生。

## 發布備註

本版重點是把 Docker Compose 驗證從「啟動指令」提升成「可重跑端到端 gate」。這補上 v1.0.24 CI workflow 仍只做到 Docker build 的缺口。

## 更新摘要

本次更新將 OTLP collector 的 production exporter 替換治理升級為正式 OTLP export governance contract gate。此切片不新增 runtime feature，重點是把 local `debug exporter` 與正式 Tempo、Jaeger、OTLP backend 或雲端 APM 的替換邊界、sampling rate、retention window、sensitive attribute redaction 與 trace data owner 納入 root `scripts/check-*-contract.mjs` inventory、Makefile、GitHub Actions、API contract、runbook、教材章節與 release artifact chain。

## 修改內容

1. 新增 `scripts/check-otel-export-governance-contract.mjs`
   - 固定 README、production README、operational runbook、API contract、OpenAPI、章節、Cheat Sheet、整合視覺課程、Makefile 與 CI 都保留 OTLP export governance contract gate。
   - 明確區分 local `debug exporter` 只供教學與 smoke review；正式環境需定義 production backend owner。

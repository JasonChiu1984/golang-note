## 更新摘要

本版將 HTTP server timeout 正式納入 `production-api-worker` 的 production contract。新增 timeout 設定、fail-fast 驗證、啟動入口套用、cmd contract test、靜態檢查腳本、Makefile target、CI gate 與教材文件同步。

## 修改內容

| 檔案 / 區域 | 修改重點 |
|---|---|
| `production-api-worker/internal/config/config.go` | 新增 HTTP read header / read / write / idle / shutdown / queue drain timeout 預設值與 env parsing |
| `production-api-worker/internal/config/config_test.go` | 覆蓋 timeout 預設值、合法 override 與不合法 duration fail-fast |

| `.github/workflows/ci.yml` | 新增 HTTP timeout static check 與 cmd contract test |

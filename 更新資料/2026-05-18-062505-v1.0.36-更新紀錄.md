## 修改摘要

本版補齊 `v1.0.35` 之後的自動化審查、更新清單、更新紀錄與版本標記。`v1.0.35` 已完成的 shutdown signal contract 與 trusted proxy rate limit 邊界持續保留；本輪重新驗證 `api-worker` 以 `monitoredSignals()` 固定監聽 `SIGINT` / `SIGTERM`，且只有 `RemoteAddr` 命中 `TRUSTED_PROXY_CIDRS` 時才採用 `X-Forwarded-For` 第一個 IP。

## 風險註記

- `TRUSTED_PROXY_CIDRS` 不應設定為全網段；只應填入受控 ingress、reverse proxy 或 load balancer 網段。
- 本輪未執行真實 Kubernetes rolling update，正式環境仍需搭配 rollout smoke test。
- 若 process manager 不轉送 `SIGTERM`，應在部署層補 signal forwarding 設定。

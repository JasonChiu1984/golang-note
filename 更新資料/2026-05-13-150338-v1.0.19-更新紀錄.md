## 本次更新重點

本輪補齊 `production-api-worker` 的 migration contract，讓資料庫 schema migration 從單純逐檔執行 SQL，提升為具備設定驗證、timeout、版本紀錄、重複執行保護與 regression test 的 production 教學範例。

## 程式碼修改

| 檔案 | 修改內容 |
|---|---|
| `production-api-worker/internal/config/config.go` | 新增 `MigrationConfig`、`LoadMigration`、`LoadMigrationFromLookup`，驗證 `DATABASE_URL`、`MIGRATIONS_DIR`、`MIGRATION_TIMEOUT` |
| `production-api-worker/internal/config/config_test.go` | 新增 migration config 預設值、合法 env、缺少 DB URL、空 migration dir、錯誤 timeout 測試 |
| `production-api-worker/internal/migration/migration.go` | 新增 migration runner、SQL 檔掃描、version 解析、`schema_migrations` 建立、已套用版本略過與 transaction apply |

| `production-api-worker/cmd/migrate/main.go` | 改為薄 CLI：載入設定、開啟 DB、ping、呼叫 migration runner |

## 4. 風險註記

- `CORS_ALLOWED_ORIGINS` 不應使用 wildcard；受保護 API 只允許 exact origin。
- 若 CORS 已由 API gateway 統一處理，應保持 application allowlist 空值，避免雙層規則漂移。
- `v1.0.35` 的 shutdown signal、trusted proxy、rate limit、OpenAPI 與 CI gate 應繼續保留。

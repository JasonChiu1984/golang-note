- 第一次直接執行 `cd production-api-worker && make ci-contract` 時，Go 使用 macOS 系統 build cache，因 sandbox 權限出現 `operation not permitted`；改用 repo-local `TMPDIR` / `GOCACHE` / `GOMODCACHE` 與 `GOFLAGS='-ldflags=-linkmode=external'` 後通過。

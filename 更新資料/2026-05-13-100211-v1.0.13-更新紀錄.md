## 更新摘要

本次依資深工程師審查結果，補齊 `production-api-worker` 的 request decoding 合約。Malformed JSON、unknown field、trailing JSON value 與空白 `name` 都會被分類為 client input error，回傳穩定 `400 invalid_input`，避免 parser error 被誤分類為 `500 internal_error`。

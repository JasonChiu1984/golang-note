## 1. 更新摘要

本輪將 Postgres connection pool 參數納入 `production-api-worker` 的 startup configuration contract。原本 repository 內硬編碼的最大開啟連線數、idle connection 數量與 connection lifetime，改由 config loader 驗證後注入 repository。

## 2. 程式更新

| 檔案 | 說明 |
|---|---|
| `production-api-worker/internal/config/config.go` | 新增 DB pool 預設值與 env 解析：`DATABASE_MAX_OPEN_CONNS=25`、`DATABASE_MAX_IDLE_CONNS=10`、`DATABASE_CONN_MAX_LIFETIME=30m0s` |
| `production-api-worker/internal/config/config_test.go` | 新增 DB pool contract tests，涵蓋預設值、合法 env、idle/open 關係與 duration 錯誤 |
| `production-api-worker/internal/repository/postgres.go` | 新增 `PoolConfig` 與 `OpenPostgresWithPool`，讓 DB pool 由外部注入 |
| `production-api-worker/cmd/api-worker/main.go` | `openStore` 改用完整 `config.Config`，將 DB pool 參數傳入 Postgres store |

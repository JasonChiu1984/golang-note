## 更新摘要

本次更新將 Go ReleaseNote generated reports 納入正式 contract gate。v1.0.60 已補齊 Syntax flow SVG contract gate；本輪審查發現 `scripts/generate-go-release-notes.mjs`、`ReleaseNote/` 與 `docs/ReleaseNote/` 雖已提供 Go 1.1-1.26 專業報告、官方來源、支援狀態與 Patch Revisions，但尚未被 root `check-*-contract.mjs` inventory 正式盤點。

v1.0.61 新增 `scripts/check-go-release-notes-contract.mjs`，固定 ReleaseNote 產生器、根目錄與 Pages 版報告同步、27 個 HTML、Go 1.1-1.26 必要報告區塊、官方文件連結、Go 1.26.4 / Go 1.25.11 於 2026-06-02 發布的 patch 訊號、Makefile 與 GitHub Actions 入口。Contract gate inventory 也從 29 個 root checker 前進到 30 個。

## 修改摘要

本次更新將 release rollback drill 從 runbook、部署章與整合視覺課程中的分散式建議，升級為正式 root static contract gate。新增 `scripts/check-release-rollback-drill-contract.mjs`，固定 rollback decision、previous image restore、migration rollback boundary、health verification、metrics verification、postmortem evidence、Makefile、GitHub Actions 與教材入口，避免 release promotion 或 incident rollback 流程在後續改版中退化成不可驗證的文字建議。

## 更新摘要

本次版本將 `production-api-worker` 的 Queue backpressure 行為提升為正式 contract gate。bounded queue 滿載時必須回 `domain.ErrQueueFull`，HTTP API 對外回 `503 queue_full`，並記錄 `worker_jobs_total{result="dropped"}` 與 queue depth，避免後續修改讓 overload 行為靜默漂移。

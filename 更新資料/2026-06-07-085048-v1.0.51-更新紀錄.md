## 更新摘要

本版把 `production-api-worker` 既有的 Request timeout 行為升級為正式 static contract gate。`context.DeadlineExceeded` 對外必須回 `504 Gateway Timeout`、`error.code=request_timeout`，並保留 `X-Request-ID`；此行為原本已有 `TestRequestTimeoutContract`，本版新增獨立 Node checker、Makefile target、GitHub Actions gate，並同步 README、API contract、OpenAPI、章節、Cheat Sheet 與整合視覺課程。

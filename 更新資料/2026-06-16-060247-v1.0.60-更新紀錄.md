## 更新摘要

本次更新將既有語法 SVG 流程圖品質檢查提升為正式 Syntax flow SVG contract gate。v1.0.59 已補齊 Production workflow contract gate；本輪審查發現 `scripts/check-syntax-flow-svg.mjs` 雖能檢查 25 個單語法流程圖、標準流程圖符號、SVG metadata 與 blueprint renderer，但它尚未被納入 `check-*-contract.mjs` inventory、Makefile 與 GitHub Actions release gate。

v1.0.60 新增 `scripts/check-syntax-flow-svg-contract.mjs`，把語法流程圖補充頁、整合來源、README、production README、API contract、OpenAPI、第 7 / 9 / 11 章、進階 Cheat Sheet、整合視覺課程、Makefile 與 CI 入口固定為可驗證 contract。Contract gate inventory 也從 28 個 root checker 前進到 29 個。

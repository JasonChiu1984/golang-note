## 4. 風險註記

- CORS 不是認證機制；正式環境仍需 API key、gateway policy、rate limit、TLS 與 WAF。
- 本版只支援 static exact allowlist，不處理多租戶動態 origin。
- 本地可驗證項目不包含真實瀏覽器跨域 E2E；需待具體前端 origin 與部署網域後補測。

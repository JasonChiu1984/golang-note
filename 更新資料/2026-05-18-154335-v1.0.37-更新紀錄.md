## 1. 修改摘要

本版正式發布 CORS allowlist contract：`production-api-worker` 預設不開跨域，只有 `CORS_ALLOWED_ORIGINS` 明確列入的 exact origin 才回 CORS header，並以 Go tests、Node contract check、Makefile、CI 與文件固定。

## 4. 風險註記

- CORS 不是認證，仍需 API key / Bearer token。
- `CORS_ALLOWED_ORIGINS` 不接受 wildcard、path、query、fragment 或 user info。
- 若正式環境已有 gateway CORS policy，需避免多層 policy 衝突。

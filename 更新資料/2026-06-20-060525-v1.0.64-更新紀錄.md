## 更新摘要

本次依照資深工程師審查結果，將建立型 API 的 retry-safe 行為升級為正式 Idempotency key contract gate。`POST /jobs` 現在可使用 `Idempotency-Key` header；同一 key 的 client retry 會回同一個 job，且不重複 enqueue worker task。

## 主要修改

- 新增 `scripts/check-idempotency-key-contract.mjs`。
- 新增 domain validation、service transaction lookup、memory/Postgres repository lookup。
- 新增 `production-api-worker/migrations/002_idempotency_key.sql`，並更新 `001_init.sql`。
- 新增 `TestIdempotencyKeyContract` 與 `TestCreateJobIdempotencyKeyContract`。

- `.github/workflows/ci.yml` 新增 `Check idempotency key contract`，並將 idempotency tests 納入 production contract job。
- README、production README、API contract、OpenAPI、第 7 / 9 / 11 章、Cheatsheet、整合視覺課程已同步 Idempotency key contract。

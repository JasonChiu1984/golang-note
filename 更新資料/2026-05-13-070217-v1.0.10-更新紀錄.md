## 修改摘要

- 將教材版本從 `v1.0.9` 更新為 `v1.0.10`。
- `production-api-worker` 新增 request correlation middleware：
  - 保留 client 提供的 `X-Request-ID`。
  - 未提供時產生 `req-*` 格式 request id。
  - 將 request id 放入 response header、request context、structured log 與 trace attribute。
- 錯誤 log 追加 `request_id`、`method`、`route`、`error_code` 等欄位，利於 incident review。
- API contract 文件新增 Request Correlation 規則與 contract gate。
- README、第 7 / 11 章、進階 Cheat Sheet、康乃爾筆記同步補上 Request ID 與 observability correlation 教學。

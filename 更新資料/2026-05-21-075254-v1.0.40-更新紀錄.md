# v1.0.40 更新紀錄

> 日期：2026-05-21  
> 完整日期時間：2026-05-21 07:52:54 CST +0800  
> 版本：v1.0.40  
> 更新主題：Request correlation contract gate

## 1. Overview

本次更新將 `X-Request-ID` request correlation 正式提升為版本化 contract gate。更新前，request id 行為已存在於 handler、tests、OpenAPI 與文件中；更新後，新增可重跑的 Node static check、Makefile target、GitHub Actions gate 與教材入口，避免後續重構造成 request correlation 漂移。

## 2. Architecture

| 檔案 | 更新內容 |
|---|---|
| `scripts/check-request-correlation-contract.mjs` | 新增 request correlation static gate |
| `.github/workflows/ci.yml` | root-course job 新增 `Check request correlation contract` |
| `production-api-worker/Makefile` | 新增 `request-correlation-check` |
| `production-api-worker/api/openapi.yaml` | 版本升級到 `v1.0.40`，補上 `X-Request-ID` / `request.id` 說明 |
| `scripts/check-openapi-contract.mjs` | OpenAPI 版本檢查更新到 `v1.0.40` |
| README / production README / API contract | 補上 Request correlation contract gate |
| 第 7 / 11 章、進階 Cheat Sheet、整合 HTML | 補上 request correlation 驗收路徑 |
| `docs/index.html` | 由整合課程重新同步並修正 Pages links |

## 3. Workflow

新 gate 驗證以下關聯不可退化：

1. `X-Request-ID` 出現在 OpenAPI request parameter 與 response header。
2. handler middleware 將 request id 寫入 response header 與 request context。
3. trace attribute 使用 `request.id`。
4. Go contract tests 固定 client supplied ID 與 server generated `req-*`。
5. README、API contract、章節、Cheat Sheet、整合 HTML、Makefile 與 CI 都保留驗收入口。

## 4. Configuration

無新增 runtime config。`X-Request-ID` 保持所有 request 預設啟用。

## 6. Troubleshooting

| 症狀 | 排查方向 |
|---|---|
| static gate 缺 `request.id` | 檢查 OpenAPI / API contract 是否保留 trace attribute 說明 |
| OpenAPI gate 失敗 | 確認 `version: v1.0.40` 與 `X-Request-ID` header 仍存在 |
| Go contract test 失敗 | 檢查 `requestContextMiddleware` 是否仍設定 response header 與 context |

## 7. Best Practices

- request correlation 應視為 API 操作合約，不是單純 logging helper。
- static gate 應同時檢查文件、實作、測試與 CI 入口。
- incident review 需要 response header、log 與 trace 使用同一個 id。

## 8. Risk Notes

- 本輪不改 API runtime 行為，主要是補強 release gate，風險低。
- 本輪未導入正式 log aggregation 或 trace backend；仍維持教學用 local / OTLP collector 邊界。

## 9. Summary

v1.0.40 補齊 Request correlation contract gate，讓 production API 教材的 observability correlation 能被 CI 與本機驗證固定。

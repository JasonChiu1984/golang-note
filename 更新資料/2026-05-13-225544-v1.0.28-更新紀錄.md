## 更新摘要

本次更新把 `production-api-worker` 的最小 API security contract 納入教材與測試。`API_KEY` 有值時，`POST /jobs`、`GET /jobs/{id}` 與 `GET /metrics` 必須使用 `Authorization: Bearer <token>`；`/livez`、`/readyz` 保持公開，避免 Docker Compose、Kubernetes 或 load balancer 探測被認證阻擋。

## 修改內容

| 類型 | 修改 |
|---|---|
| Code | `internal/config` 新增 `APIKey`；`internal/api` 新增 auth middleware 與 security headers middleware |
| Tests | 新增 `TestAPIKeyAuthContract`、`TestSecurityHeadersContract`，config test 固定 `API_KEY` trim |
| Runtime | `cmd/api-worker` 注入 `cfg.APIKey`；`docker-compose.yml` 支援 `${API_KEY:-}` |
| Smoke | `compose-smoke.sh` 支援 `API_KEY` 並送 Bearer token |
| Documentation | README、production README、API contract、第 7 / 11 章、進階 Cheat Sheet、整合視覺課程同步更新 |
| Docs Pages | 重新同步 `docs/index.html` 並執行 Pages link fix |

## 一、本輪更新摘要

本輪依資深工程師審查結果，補齊 `production-api-worker` 的 request timeout contract。上一版已讓 service deadlock retry 尊重 `context` cancellation，但 HTTP handler 對 `context.DeadlineExceeded` 尚未形成穩定外部合約，會落回 `500 internal_error`。本版將 timeout 明確分類為 `504 request_timeout`，並同步教程、合約文件與測試 gate。

## 二、程式碼更新

| `production-api-worker/internal/api/handler_test.go` | 新增 `TestRequestTimeoutContract`，用測試專用 `contextWithTimeout` 產生 expired deadline，固定 status、error code 與 `X-Request-ID` |

## 更新摘要

本版把教材中多次提到的 CI / release gate 轉成 repo 內真實可執行的 GitHub Actions workflow，讓 Go 教學不只說明 production 測試策略，也提供讀者可直接參考的 workflow、Makefile target 與本機驗證指令。

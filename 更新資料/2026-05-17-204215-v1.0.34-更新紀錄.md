## 1. 更新摘要

本次更新把 production API 的過載保護補成可重跑的 Rate limit contract。教材現在固定 `RATE_LIMIT_REQUESTS_PER_MINUTE`、per-client IP window、`429 rate_limited` error envelope、`Retry-After` header、OpenAPI spec、Go tests、README、runbook、章節、整合 HTML 與 CI gate。

## 4. Release Notes

- Rate limiter 目前採單 process memory 固定時間窗，適合教材與單副本 local runtime。
- 多副本正式環境需改由 API gateway、Redis、service mesh 或 load balancer 層做全域限速。
- 正式 reverse proxy 必須明確定義 `X-Forwarded-For` 信任邊界，避免 client 偽造來源 IP。
- Health endpoint 不受限速影響，避免 Kubernetes / Compose / LB 探測被誤擋。

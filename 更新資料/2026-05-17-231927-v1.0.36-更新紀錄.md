## 4. Release Notes

- `TRUSTED_PROXY_CIDRS` 預設空值，代表不信任任何 forwarded header。
- 只有 trusted proxy 來源才會用 `X-Forwarded-For` 第一個 IP 作為 rate limit key。
- SIGINT 與 SIGTERM 都會觸發 readiness draining、HTTP shutdown 與 queue drain。
- 多副本全域限速仍需 API gateway、Redis、service mesh 或 load balancer 層處理。

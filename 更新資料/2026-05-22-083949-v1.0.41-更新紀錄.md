## 4. 風險與後續

- 本輪不新增 OAuth2、JWT、mTLS 或 API gateway，避免把教學範例過度平台化。
- 後續若要補正式 production security，可另開版本處理 secret rotation、Prometheus bearer token file、API gateway policy、mTLS 與 RBAC。
- 若 CI 或 Docker 環境無法執行，需在最終發布摘要中分開標示本地通過項目與環境限制。

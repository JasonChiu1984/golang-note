## 修改摘要

- 新增 `REQUEST_BODY_LIMIT_BYTES` 啟動設定，預設 `1048576` bytes。
- `POST /jobs` oversized request body 現在固定回 `413 payload_too_large`，並保留 `X-Request-ID`。
- 新增 `TestRequestBodyLimitContract`，並擴充 config tests。
- 新增 `scripts/check-request-body-limit-contract.mjs`、`make request-body-limit-check` 與 CI workflow step。
- 更新 OpenAPI `v1.0.38`、API contract、README、production README、第 7 / 11 章、進階 Cheat Sheet 與整合視覺課程。
- 已重新同步 `docs/index.html` 作為 GitHub Pages 入口。

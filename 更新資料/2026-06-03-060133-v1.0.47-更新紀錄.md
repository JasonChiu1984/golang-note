## 更新摘要

本次更新將既有 Panic recovery behavior 升級為正式 static gate。handler、service 或 queue 發生未預期 panic 時，`production-api-worker` 必須穩定回 `500 internal_error` JSON、保留原 `X-Request-ID`，並由 Go contract test、Node static check、Makefile、GitHub Actions、OpenAPI、API contract、README、章節與 GitHub Pages 首頁共同固定。

## 主要修改

- 新增 `scripts/check-panic-recovery-contract.mjs`。

- `.github/workflows/ci.yml` 新增 `Check panic recovery contract`。
- `README.md` 新增 Panic recovery contract 策略、驗證列與本輪更新重點。
- `production-api-worker/README.md` 將 Panic recovery 升級為正式 contract gate。

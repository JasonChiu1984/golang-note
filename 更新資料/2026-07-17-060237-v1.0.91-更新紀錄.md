## 本輪新增 gate

Dependency audit evidence freshness contract gate 要求每次 release 保留 root module 與 `production-api-worker` 的 dependency audit evidence：

- `go mod tidy`
- `go mod verify`
- `go list -m -u all`
- `govulncheck ./...`
- module proxy / vulnerability database 離線時只能標示待補掃描
- release evidence retention 必須能追溯 root / production module coverage

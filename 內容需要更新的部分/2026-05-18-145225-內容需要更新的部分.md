## 4. 不在本輪處理

| 項目 | 原因 |
|---|---|
| 真實瀏覽器跨域 E2E | 需要具體前端 origin 與部署網域 |
| Cookie credential mode | 目前 API 使用 Bearer token，不引入 cookie/session 教學 |
| Gateway / WAF CORS policy | 需依實際 Ingress、API Gateway 或 CDN 產品設定 |
| 多租戶動態 origin | 會提高設定與快取風險，本輪先固定 exact allowlist |

## 5. Troubleshooting

| 症狀 | 文件需補充 |
|---|---|
| `/debug/pprof/` 回 404 | 表示 `ENABLE_PPROF` 未啟用，屬於預設安全行為 |
| `/debug/pprof/` 回 401 | Bearer token 缺失或不符 |
| `go tool pprof` 無法直接抓需 token endpoint | 先用 `curl -H 'Authorization: Bearer ...'` 下載 profile，再用 `go tool pprof` |

## 6. Best Practices

1. 不把 pprof route 常態公開。
2. 不把 profile 檔案提交到 repo。
3. 不用 pprof 取代 metrics / trace；先用 SLI 定位症狀。
4. 新增 diagnostics 能力時同步補 code、test、runbook、README、CI 與 release note。

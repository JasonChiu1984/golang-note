## 驗收重點

- `/readyz` ready 時回 200，draining 時回 503。
- Worker context 不因 signal 立刻取消，queue 有機會 drain 已排入 task。
- README 與章節能清楚區分 liveness、readiness、HTTP shutdown、queue drain。
- 測試結果需誠實記錄受限環境的 module download / DNS 問題，不把未跑通的 production tests 標為通過。

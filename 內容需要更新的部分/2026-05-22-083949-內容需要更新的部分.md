## 2. 不在本輪擴張

| 項目 | 原因 |
|---|---|
| OAuth2 / OIDC | 超出目前 production skeleton 教材邊界 |
| JWT claims / RBAC | 需獨立章節與 threat model，不宜塞入最小 API security gate |
| mTLS / API gateway | 屬部署拓撲與平台治理，後續可另開版本補充 |
| Prometheus bearer token file 實作 | 本輪只固定 API security 教學合約；正式 scrape auth 可留在 deployment hardening 後續項 |

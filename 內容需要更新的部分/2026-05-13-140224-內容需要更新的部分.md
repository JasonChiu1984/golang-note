## 1. 本輪更新主題

補齊 `production-api-worker` 的 **Postgres connection pool contract**，避免 DB pool 容量被硬編碼在 repository 層，並讓 DB pool 參數成為 startup configuration contract 的一部分。

## 2. 需要修改的程式

| 檔案 | 更新內容 |
|---|---|
| `production-api-worker/internal/config/config.go` | 新增 `DATABASE_MAX_OPEN_CONNS`、`DATABASE_MAX_IDLE_CONNS`、`DATABASE_CONN_MAX_LIFETIME` 預設值、解析與 fail-fast 驗證 |
| `production-api-worker/internal/config/config_test.go` | 新增 DB pool 預設值、合法 env、idle/open 關係與 duration 錯誤測試 |
| `production-api-worker/internal/repository/postgres.go` | 新增 `PoolConfig` 與 `OpenPostgresWithPool`，保留 `OpenPostgres` 相容 wrapper |
| `production-api-worker/cmd/api-worker/main.go` | 將 config 解析出的 DB pool 參數注入 repository |

## 4. 預期驗收

| 驗收項 | 標準 |
|---|---|
| DB pool 設定可由 env 控制 | `DATABASE_MAX_OPEN_CONNS`、`DATABASE_MAX_IDLE_CONNS`、`DATABASE_CONN_MAX_LIFETIME` 可被 config loader 讀取 |
| 不合法設定 fail fast | 非正整數、idle 大於 open、duration 格式錯誤都回 error |
| repository 不自行讀 env | `cmd/api-worker` 負責 configuration wiring |
| docs 同步 | README、章節、Cheat Sheet、康乃爾筆記與 API contract 都描述同一個合約 |
| docs/index.html 同步 | 由 `圖解筆記3-4整合/golang-complete-visual-course.html` 複製成 `docs/index.html`，並保留 GitHub Pages 可用的 release-note 相對路徑 |

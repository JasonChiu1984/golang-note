## 3. 風險註記

- `TRUSTED_PROXY_CIDRS` 不應填入外部 client 網段；只允許內部 proxy / ingress / gateway CIDR。
- 多副本全域限速仍需 gateway、Redis 或 service mesh，application memory limiter 只示範單 process contract。
- SIGTERM 的完整 e2e 行為仍建議在 Docker Compose / Kubernetes staging 中補 process-level 驗證。

## 驗收條件

| Gate | 指令 |
|---|---|
| Shell syntax | `bash -n production-api-worker/scripts/compose-smoke.sh` |
| Make target | `cd production-api-worker && make -n compose-smoke` |
| YAML syntax | `ruby -e 'require "yaml"; YAML.load_file(".github/workflows/ci.yml")'` |
| 文件同步 | `cmp 圖解筆記3-4整合/golang-complete-visual-course.html docs/index.html` |
| Go tests | root `go test ./... -count=1` 與 production contract tests |
| Compose runtime | `cd production-api-worker && docker compose up -d --build && make compose-smoke && docker compose down -v` |

## 注意事項

- 若本機 Docker daemon 未啟動，Compose runtime gate 只能標示為環境阻擋。
- smoke script 不依賴 `jq`，避免 CI runner 額外安裝工具。
- 不在 distroless runtime image 內加入 shell 或 curl，避免為了 healthcheck 擴大 runtime attack surface。

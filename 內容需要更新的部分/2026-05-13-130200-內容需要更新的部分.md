## 本輪更新主題

補齊 `production-api-worker` 的 **startup configuration contract**。目前 API、timeout、panic recovery、retry cancellation 與 queue shutdown 都已有合約與測試保護，但服務啟動設定仍會 silent fallback，部署錯誤不會 fail fast。

## 驗收標準

1. `PORT`、`QUEUE_SIZE`、`WORKERS` 有明確預設值。
2. 不合法 `PORT`、`QUEUE_SIZE`、`WORKERS` 會回傳設定錯誤，不會 silent fallback。
3. `cmd/api-worker` 在設定錯誤時 fail fast。
4. `go test ./internal/config -count=1` 通過。
5. README、第 7 / 11 章、Cheat Sheet、康乃爾筆記與 `production-api-worker` 文件均可找到 startup config contract / config test gate。
6. `VERSION` 與 `CHANGELOG.md` 標註 v1.0.17。
7. `docs/index.html` 已同步整合課程 HTML。

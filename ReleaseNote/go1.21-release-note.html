Go 1.21：標準庫泛型工具與 toolchain 管理成形

Go 1.21 是現代 Go 日常開發的重要分水嶺：泛型集合工具進入標準庫，結構化日誌落地，工具鏈版本管理也更明確。

語言

內建函式補強

  • min、max、clear 成為內建函式。
  • panic(nil) 行為改得更可觀測，recover 直接呼叫時不再得到 nil。
標準庫

泛型集合與結構化日誌

  • slices、maps、cmp 讓常用集合操作回到標準庫。
  • log/slog 提供官方結構化日誌 API，適合 API、worker、CLI 共用欄位語意。
工具鏈

go / toolchain directive

Go 1.21 將 go directive 視為更嚴格的最低版本要求，並引入 toolchain directive，讓專案可以明確建議使用較新的工具鏈。

效能

PGO Auto

-pgo=auto 讓主套件目錄中的 default.pgo 可自動被使用。這讓效能優化更適合納入 release pipeline。

升級檢查表

檢查項建議
集合工具把手寫 key collection、clone、sort、delete 邏輯逐步改用 slices / maps。
日誌新服務優先設計 slog 欄位規格，例如 request_id、trace_id、error_kind。
版本策略明確分離 go 最低版本與 toolchain 建議版本。
GODEBUG升級後若遇行為差異，先查 go.mod 版本與 GODEBUG 相容設定。

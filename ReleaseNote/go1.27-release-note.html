2026-11-10 安全修補：12 項公告

Go 1.27.4／1.26.11 修補 CVE-2026-97033–97043 與 CVE-2026-97054。這是 patch 安全修補，不是新增語法。

官方漏洞範圍：Go <1.26.11，以及 Go >=1.27.0-0 且 <1.27.4；第一段未列更早引入版本。只列支援分支時，影響 1.26.0–1.26.10、1.27.0–1.27.3。

  • HTTP/1 拒絕服務：MaxBytesReader／MaxBytesHandler 的 body 超限，且 handler 並行讀 body／寫 header 時可能 race／panic。升級後須重建並部署程式。
  • 建置供應鏈：其餘 11 項涉及惡意套件、cgo／.syso／linker input 或 compiler directives。先修補本機與 CI builder；不能概括為所有 Go 服務都能被遠端 RCE，也不能因 CGO_ENABLED=0 就一概判定安全。

這 12 項與本倉庫原 CI 回報的 13 個第三方相依漏洞是不同清單。本次只更新筆記，未升級 production 相依或部署環境。

分類新增功能 / 行為功能說明工程導入建議驗證方式
Language / 語法generic methods具體型別的方法可宣告自己的型別參數。介面方法不能宣告型別參數，泛型方法也不能用來實作介面方法。把相關泛型操作放進型別的方法命名空間。以 examples/go127 中的泛型方法測試驗證；介面限制另作 compile-negative 測試。
Language / 語法struct literal field selectorsstruct literal 可直接以 promoted 欄位名稱作 key，例如 Outer{Value: 7}；不是 Outer{Inner.Value: 7} 這種 dotted key。selector 必須無歧義、不可經過 embedded pointer，且不得重疊初始化同一欄位。以 examples/go127 中嵌入欄位 literal 測試驗證。
Language / 型別推論generalized function type inference泛型函式指定給相符函式型別變數、或轉換為相符函式型別時，可在更多上下文由目標型別推論。不是任意省略所有型別參數；無足夠型別資訊時仍需明寫。以 examples/go127 中函式型別轉換測試驗證。

Release Note 專欄 / Go 1.20

Go 1.20：PGO、整合覆蓋率與工具鏈細節升級

Go 1.20 的主軸是讓大型專案更容易量測、最佳化與自動化；語言變動不大，但工具鏈、coverage、PGO preview 與標準庫錯誤處理很值得納入工程流程。

語言與型別

開發者應知道的語法變化

  • 支援從 slice 直接轉成 array，讓固定長度資料處理更清楚。
  • comparable 約束更符合實務泛型需求，但介面值比較仍可能在 runtime panic。
  • unsafe 補齊 slice / string 底層資料存取 API，適合底層函式庫作者，不適合一般業務碼濫用。
工具鏈

Build / Test / Coverage

  • go test -json 輸出更穩定，適合 CI 收集測試事件。
  • go 子命令加入 -C，多 module 腳本可少寫 shell 切目錄邏輯。
  • go build -cover 與 GOCOVERDIR 讓整合測試與長時間服務也能收 coverage。
效能

PGO Preview

Go 1.20 讓 profile-guided optimization 進入 preview。對 CPU 熱路徑明顯的服務，可用 production-like profile 驅動編譯器做更好的 inline 決策。

標準庫

錯誤與 Context

  • errors.Join 適合彙整多個失敗原因，保留 errors.Is / errors.As 判斷能力。
  • context.WithCancelCause 讓取消原因可以被上層觀測，適合排查 worker 或 request lifecycle。

升級檢查表

檢查項建議
CI 測試輸出若已消費 go test -json，確認 parser 能處理 start event。
Coverage把整合測試與 CLI smoke test 納入 GOCOVERDIR 報表。
效能先建立穩定 benchmark / pprof，再評估 -pgo。
平台注意 Go 1.20 是部分舊 Windows / macOS 版本的最後支援線。

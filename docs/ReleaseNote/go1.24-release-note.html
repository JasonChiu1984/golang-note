Release Note 專欄 / Go 1.24

Go 1.24：工具依賴、檔案系統邊界與安全標準庫補強

Go 1.24 對 production 專案很實用：go.mod 可追蹤 tool dependency，os.Root 提供受限檔案系統操作，benchmark、finalizer、安全密碼學也都有重要更新。

語言

Generic Type Aliases

泛型 type alias 進入正式支援，讓大型專案在重構 package 邊界、保留 API 相容時更有彈性。

工具鏈

Tool Directive

  • go.mod 可用 tool directive 管理可執行工具依賴。
  • go tool 可執行 module 追蹤的工具，減少傳統 tools.go workaround。
  • go build -json 與 go test -json build output 更利於 CI 平台解析。
安全

os.Root 與 Crypto

  • os.Root 讓檔案操作限制在指定目錄內，適合處理 upload、解壓縮、template 檔案。
  • 新增 crypto/mlkem、crypto/hkdf、crypto/pbkdf2、crypto/sha3 等套件。
Runtime

Swiss Table Map 與 Cleanup

runtime map 實作採用 Swiss Table 方向，並新增 runtime.AddCleanup 與 weak package，讓資源釋放與弱參照場景更安全。

升級檢查表

檢查項建議
工具依賴把 lint、generator、mock 工具逐步遷移到 tool directive。
檔案安全上傳、解壓縮、使用者指定路徑優先評估 os.Root。
Benchmark新 benchmark 可使用 testing.B.Loop，減少手寫 b.N 陷阱。
加密優先使用標準庫 crypto 新套件，減少額外 dependency 面積。

Release Note 專欄 / Go 1.26

Go 1.26：語言小幅精簡，Runtime 與標準庫持續現代化

Go 1.26 補上 new(expression)、泛型自我參照約束、Green Tea GC、測試 artifact、errors.AsType 與多個標準庫效能/安全改進，是 2026 教材基準的重要版本。

語言

new(expression) 與泛型約束

  • new 可直接接 expression，例如 p := new(42)。
  • 泛型型別可在 type parameter list 中參照自己，讓自我約束資料結構更自然。
Runtime

Green Tea GC

Green Tea GC 成為預設 GC，重點在改善小物件標記與掃描 locality。實務上仍要用 pprof、runtime metrics 與壓測確認工作負載是否受益。

Testing

ArtifactDir

  • T.ArtifactDir、B.ArtifactDir、F.ArtifactDir 可讓測試產物有固定輸出位置。
  • 適合 golden diff、截圖、profile、fuzz repro，由 CI 收集留證。
標準庫

errors.AsType 與 I/O 改進

  • errors.AsType 是泛型版 errors.As，更型別安全也更易讀。
  • io.ReadAll 減少中間配置，對大量讀取更友善。
  • log/slog.NewMultiHandler 方便把同一筆 log 送到多個 handler。

升級檢查表

檢查項建議
語法採用new(expression) 適合 optional field 與測試資料，但不要降低可讀性。
GC 驗證升級後重跑 allocation profile、latency benchmark、memory limit 壓測。
測試證據把需要留存的 diff、截圖、profile 改寫到 artifact 目錄。
錯誤處理新碼可用 errors.AsType，舊碼不必一次性機械替換。

Go 1.22：迴圈變數修正與標準庫路由升級

Go 1.22 對日常後端開發很有感：for loop 變數捕獲陷阱被修正，標準庫 ServeMux 可處理 method 與 path variable，基本 REST API 不再一定要第三方 router。

語言

Loop Variable Fix

  • for 迴圈每次迭代會建立獨立變數，減少 goroutine / closure 捕獲同一變數的 bug。
  • for i := range 10 這類整數 range 可讓計數迴圈更簡潔。
HTTP

ServeMux Patterns

  • 路由 pattern 可包含 HTTP method，例如 GET /users/{id}。
  • 可用 r.PathValue("id") 取得 path variable。
  • 簡單 CRUD API 可先用標準庫，複雜 middleware graph 再導入 router。
標準庫

math/rand/v2

第一個標準庫 v2 package 出現。新版亂數 API 命名更一致，預設 top-level generator 自動隨機 seed，適合非密碼用途的隨機邏輯。

工具

go/version 與 Workspace

go/version 讓版本字串比較更可靠；workspace vendor 支援讓多 module 專案在封閉環境中更可控。

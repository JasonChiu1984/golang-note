Overview

Go 微服務的價值不只是 HTTP server，而是可部署、可觀測、可設定、可測試、可維護的服務邊界。

服務邊界

清楚 API contract

每個 endpoint 都要有固定 request/response/error schema，避免前端、SCADA gateway 或 batch job 對錯誤格式做猜測。

可靠性

Timeout 與 graceful shutdown

HTTP server 必須有 read header timeout、request timeout、shutdown timeout，避免慢連線與卡住的 downstream 拖垮服務。

維運

Health、log、metrics

最小 production 服務要有 /livez、/readyz、結構化 log、request id 與可重跑 smoke test。

Architecture

把 HTTP、service logic、資料存取、觀測性與設定分層，讓每一層都可單獨測試與替換。

架構重點：每個邊界只做自己的事，測試與排錯才會清楚。

Setup

此範例只用 Go 標準庫，先建立 production-oriented 的最小服務骨架，再視需求加入 Gin、Fiber、pgx、Prometheus 或 OpenTelemetry。

建立專案骨架
mkdir go-microservice
cd go-microservice
go mod init example.com/go-microservice
mkdir -p cmd/server internal/api internal/config internal/service scripts
資料夾責任不要放什麼
cmd/server啟動 server、載入 config、接 signal。不要放 business logic。
internal/apiHTTP routing、JSON decode/encode、status code。不要直接操作資料庫。
internal/service用例邏輯、timeout、輸入規則。不要依賴 http.ResponseWriter。
internal/config環境變數解析與驗證。不要在 handler 裡讀 env。

Configuration

設定必須 fail fast。錯誤的 port、timeout 或 queue size 應在服務啟動時失敗，而不是讓 production request 才撞錯。

Env

建議設定

  • PORT=8080：HTTP listen port。
  • REQUEST_TIMEOUT=2s：單次業務 timeout。
  • SHUTDOWN_TIMEOUT=10s：graceful shutdown 最大等待。
  • LOG_LEVEL=info：本地與 production 可切換。
工業現場提醒

若服務接 PLC、DDC、OPC UA、Modbus 或 BACnet endpoint，timeout 要依設備反應時間、網段延遲、retry 次數與 fail-safe 策略設計，不要沿用 Web API 預設值。

Example

範例 API：POST /score 接收整數陣列並回傳 score；/livez 與 /readyz 用於容器與負載平衡檢查。

internal/config/config.go
package config

import (
	"fmt"
	"os"
	"strconv"
	"time"
)

type Config struct {
	Port            int
	RequestTimeout  time.Duration
	ShutdownTimeout time.Duration
}

func Load() (Config, error) {
	port, err := intEnv("PORT", 8080)
	if err != nil {
		return Config{}, err
	}
	return Config{
		Port:            port,
		RequestTimeout:  durationEnv("REQUEST_TIMEOUT", 2*time.Second),
		ShutdownTimeout: durationEnv("SHUTDOWN_TIMEOUT", 10*time.Second),
	}, nil
}

func intEnv(key string, fallback int) (int, error) {
	raw := os.Getenv(key)
	if raw == "" {
		return fallback, nil
	}
	value, err := strconv.Atoi(raw)
	if err != nil || value <= 0 {
		return 0, fmt.Errorf("%s must be a positive integer", key)
	}
	return value, nil
}

func durationEnv(key string, fallback time.Duration) time.Duration {
	raw := os.Getenv(key)
	if raw == "" {
		return fallback
	}
	value, err := time.ParseDuration(raw)
	if err != nil || value <= 0 {
		return fallback
	}
	return value
}
internal/service/score.go
package service

import "context"

type ScoreService struct{}

func (s ScoreService) Score(ctx context.Context, values []uint64) (uint64, error) {
	select {
	case <-ctx.Done():
		return 0, ctx.Err()
	default:
	}
	var total uint64
	for _, value := range values {
		total += value
	}
	return total, nil
}
internal/api/handler.go
package api

import (
	"context"
	"encoding/json"
	"errors"
	"log/slog"
	"net/http"
	"time"

	"example.com/go-microservice/internal/service"
)

type Handler struct {
	score   service.ScoreService
	timeout time.Duration
	logger  *slog.Logger
}

type ScoreRequest struct {
	Values []uint64 `json:"values"`
}

type ScoreResponse struct {
	Score uint64 `json:"score"`
}

type ErrorResponse struct {
	Code    string `json:"code"`
	Message string `json:"message"`
}

func New(timeout time.Duration, logger *slog.Logger) http.Handler {
	h := Handler{score: service.ScoreService{}, timeout: timeout, logger: logger}
	mux := http.NewServeMux()
	mux.HandleFunc("GET /livez", h.livez)
	mux.HandleFunc("GET /readyz", h.readyz)
	mux.HandleFunc("POST /score", h.scoreRoute)
	return mux
}

func (h Handler) livez(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusNoContent)
}

func (h Handler) readyz(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusNoContent)
}

func (h Handler) scoreRoute(w http.ResponseWriter, r *http.Request) {
	ctx, cancel := context.WithTimeout(r.Context(), h.timeout)
	defer cancel()

	var input ScoreRequest
	if err := json.NewDecoder(r.Body).Decode(&input); err != nil {
		writeError(w, http.StatusBadRequest, "invalid_json", "request body must be valid JSON")
		return
	}
	score, err := h.score.Score(ctx, input.Values)
	if errors.Is(err, context.DeadlineExceeded) || errors.Is(err, context.Canceled) {
		writeError(w, http.StatusGatewayTimeout, "request_timeout", "request timed out")
		return
	}
	if err != nil {
		h.logger.Error("score failed", "error", err)
		writeError(w, http.StatusInternalServerError, "internal_error", "internal error")
		return
	}
	writeJSON(w, http.StatusOK, ScoreResponse{Score: score})
}

func writeJSON(w http.ResponseWriter, status int, body any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(body)
}

func writeError(w http.ResponseWriter, status int, code, message string) {
	writeJSON(w, status, ErrorResponse{Code: code, Message: message})
}
cmd/server/main.go
package main

import (
	"context"
	"fmt"
	"log"
	"log/slog"
	"net/http"
	"os"
	"os/signal"
	"syscall"

	"example.com/go-microservice/internal/api"
	"example.com/go-microservice/internal/config"
)

func main() {
	cfg, err := config.Load()
	if err != nil {
		log.Fatal(err)
	}
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
	server := &http.Server{
		Addr:              fmt.Sprintf(":%d", cfg.Port),
		Handler:           api.New(cfg.RequestTimeout, logger),
		ReadHeaderTimeout: cfg.RequestTimeout,
	}

	go func() {
		logger.Info("server listening", "addr", server.Addr)
		if err := server.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			log.Fatal(err)
		}
	}()

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, syscall.SIGINT, syscall.SIGTERM)
	<-stop

	ctx, cancel := context.WithTimeout(context.Background(), cfg.ShutdownTimeout)
	defer cancel()
	if err := server.Shutdown(ctx); err != nil {
		log.Fatal(err)
	}
	logger.Info("server stopped")
}

set -eu

go test ./... -count=1

scripts/smoke.sh
#!/usr/bin/env sh
set -eu

BASE_URL="${BASE_URL:-http://127.0.0.1:8080}"
curl -fsS "$BASE_URL/livez" -o /dev/null
curl -fsS "$BASE_URL/readyz" -o /dev/null
curl -fsS -X POST "$BASE_URL/score" \
  -H 'Content-Type: application/json' \
  -d '{"values":[1,2,3,4,5]}'
Dockerfile
FROM golang:1.22-alpine AS build
WORKDIR /src
COPY go.mod ./
COPY . .
RUN go build -trimpath -ldflags="-s -w" -o /out/server ./cmd/server

FROM alpine:3.20
RUN adduser -D -H app
USER app
COPY --from=build /out/server /server
EXPOSE 8080
ENTRYPOINT ["/server"]

Verification

微服務驗證不只看編譯通過，還要確認 API contract、health endpoint、timeout、shutdown 與容器 smoke test。

驗證項指令通過條件
Unit testgo test ./... -count=1config、service、api tests 全部通過。
Race testgo test -race ./...handler、service、shared state 無 race。
Health checkcurl -i /livez、curl -i /readyz回傳 204 或明確 JSON 狀態。
API contractcurl -X POST /score成功回傳 {"score":15}；錯誤回傳固定 code/message。
Docker smokedocker build + scripts/smoke.sh容器內服務可被 host smoke test 驗證。

Troubleshooting

微服務問題通常來自設定、timeout、錯誤格式、health check 或 downstream 依賴，而不是 Go 語法本身。

症狀可能原因處理方式
服務啟動後立刻退出設定驗證失敗或 port 被佔用。檢查 PORT、啟動 log 與 lsof -i :8080。
curl 卡住沒有 request timeout 或 downstream 阻塞。在 service 層傳遞 context，並設定 server timeout。
容器 ready 但 API 失敗/readyz 沒檢查必要依賴。把 DB、queue、外部 gateway 連線狀態納入 readiness。
錯誤格式不一致各 handler 自己寫錯誤。集中 writeError，固定 code/message schema。
工業設備資料過期polling timeout 或 stale data 未分類。增加 device_timeout、stale_value、bad_quality 錯誤碼。

Best Practices

微服務的重點是可維運。功能可以小，但 contract、timeout、log、health 與 smoke test 不能省。

Do
  • handler 只處理 HTTP boundary。
  • service 接收 context 並尊重 timeout。
  • 啟動時驗證所有重要環境變數。
  • 所有錯誤都回傳固定 code/message。
  • 建立 smoke script，讓 Docker/CI/local 共用。
Avoid
  • 在 handler 內直接寫資料庫或設備通訊邏輯。
  • 用預設 timeout 處理 PLC / DDC / SCADA 場景。
  • 只靠 console log 排查 production incident。
  • 讓 readiness 永遠回 200 卻不檢查依賴。
  • 把架構設定藏在程式碼常數中。
